## 2. 协议关键结论(已查证,勿再翻手册推翻)

- **两代均无使能环节**:上电直接发闭环指令;0x80 关闭/0x81 停止。
- **V3.9（V3.91 为旧英文资料名）**:0x20 仅有索引 0x01/0x02;**无多圈掉电保存**;0x60/0x61/0x62/0x63/0x64 实测全部无效(写 ROM 类被固件砍掉);**X8/X6-S2 = 转子侧单圈绝对值编码器** + **固件多圈角(0x92 可读,D1~4 int32 0.01°/LSB,会被 0xA8 增量污染成 ±360N)**;**0xA4 = 多圈绝对角目标,固件按「目标−当前」差值直接执行**(非最短路径、非单圈相位)→ 终版:0x92 轮询校准 rotDeg 到固件角 + **E0 存凸点固件角(含圈号,非相位!)** + 0xA4 发 R_t=E0+out2rot(deg);详见技术归档.md「问题 E」(含 12 条踩坑全记录);0x79 改 ID 发往固定地址 0x300(旧款拨杆设 ID,0x79 无效);0xA1 力矩在 **D4~5**;0x9C D6~7=16 位编码器脉冲(相位源)。
- **V4.3（X6-40 当前实测支持）**:索引参数结构、兼容特征和 0x94 两字节单圈格式均已在协议自测页得到正向证据；这确认 X6-40 的 V4.3 方向，但协议特有写入仍须逐项验证，不得把 V4.4 写入行为直接套用。
- **V4.4（候选行为）**:0x20 共 8 索引、索引 4 多圈掉电保存、索引 5 设编号等均来自 V4.4 资料；在 X6-40 的 V4.4 专有写入未独立验证前，不得把这些写入行为直接套用到 X6-40。
- **当前只读特征探测**:协议确认页「开始安全确认」会读取基础信息并追加 0x79 只读、0x90 只读、0x94 单圈格式；页面不显示指令号，只输出兼容特征、单圈读数格式和「更支持 V4.3/V4.4/仍无法区分」。单圈值恰在零点时可人工轻微转动后点击「补充协议特征」重试；无响应不得单独推出 V4.4。
- **两代均无全局方向反转指令**(0xA6 spinDirection 仅单次)→ 方向一致性只能软件映射;一体化 FOC 换相线不可行。
- 关键差异对照详见 技术归档.md 与 index.html 内 BUILD_V3/BUILD_V44。

## 4. 方向映射架构(index.html,本轮 2026-08-15 实现)

- 注册表条目字段:`dir: 1(正转,默认)| -1(反转)`;载入时两处归一化(`loadMotors` 与脚本顶部 localStorage 载入):`motors = motors.map(x => ({...x, dir: x.dir === -1 ? -1 : 1}))`。
- 核心函数(约 line 706~715):
  ```js
  gearOf(m)  // 减速比,缺省 1
  dirOf(m)   // 1|-1,缺省/0 归一 1
  out2rot(v,m) = v * gearOf(m) * dirOf(m)   // 输出轴→协议侧(组帧)
  rot2out(v,m) = v / gearOf(m) * dirOf(m)   // 协议侧→输出轴(显示)
  amp2rot(v,m) = v * dirOf(m)               // 力矩电流 A:只映方向不乘减速比
  spd2rot(v,m) = Math.abs(out2rot(v,m))     // 无符号上限速度字段(0xA4/0xA6/0xA9 D2~3)取幅度
  ```
- 接入点:所有闭环发送(v3Pos/v3Pos1/v3Speed/v3Torque/v44Pos/v44PosInc/v44Speed/v44Torque/v44ForcePos/v44FFSpd/v44FFTq);parseReply 内 `rm = motorById(n) || selMotor()` 按回复归属电机映射;V3 位置累积 v3PosFromEnc ×dir;0x92 校准 `t.revs = a/360*gear*dir`;updateStatusPanel 的 chart.feed 与面板数值;0xA6 负角度→取正+spinDirection 翻转。
- 不映射:0x280 广播、手动发帧(原样发送,UI 有提示)。
