# 脉塔电机调试上位机

> 同时调试**三种协议**（V3.9/V4.3/V4.4）脉塔伺服电机的全中文 CAN 调试工具
> **双击即用**：无需安装、无需 Python、拷走整个文件夹就能跑

---

# 📖 第一部分：用户手册（小白友好）

## 它能干什么

一台软件同时驱动新旧两代脉塔电机，混接在**同一条 CAN 总线**上：

```
  ┌──────────┐   USB    ┌──────────┐    CAN Bus    ┌──────────────┐
  │   电脑     │ ◄──────▶ │ USBCAN 模块│ ◄───────────▶ │ 电机 1~32 台   │
  │ 上位机.exe │  即插即用 │ (ZLG 系)  │   1Mbps      │ V3旧款 + V4新款 │
  └──────────┘          └──────────┘               └──────────────┘
```

| 电机 | 协议 | 例子 |
|------|------|------|
| **V3.x 旧款**（RMD-X 系列） | V3.9 | X8-PRO 1:6、X6-S2 1:36 |
| **V4.3 新款** | V4.3（X6-40 只读自测支持） | X6-40 |
| **V4.4 新款候选** | V4.4（X2-7；X6-40 不再按此归类） | X2-7 |

**核心能力**：电机注册表（断电不丢）、全总线扫描、位置/速度/力矩闭环、**限幅安全链（软件硬上限：发送前校验 + 运行中角度/速度/电流越限自动停止并报警，报警详情入日志）**、PID 读写、掉电记忆、方向软件映射、多圈角度（0x92）、机械零点标定、实时曲线、多电机 0x280 广播、手动发帧、全量收发日志；**状态监控角度 = 相对机械零点的输出轴角度（0.01° 精度）**。

---

## 第 1 步：运行（1 分钟）

1. 双击 `dist\上位机\上位机.exe`；
2. 若提示缺 WebView2 运行时，按弹窗在线安装一次（仅首台电脑需要）；
3. 杀毒软件误报属正常（PyInstaller 打包常见），添加信任即可。

## 第 2 步：连接与添加电机（2 分钟）

1. USBCAN 模块插 USB，CAN 总线接电机（CAN_H↔CAN_H、CAN_L↔CAN_L，两端 120Ω 终端电阻）；
2. 电机 24V 上电；
3. 点「**打开设备**」→「**扫描在线电机**」；
4. 点「**➕ 添加**」登记电机：名称 / 编号 1~32 / **协议版本（X6-40 选 V4.3）** / 减速比（X8-PRO 填 6、X6-S2 填 36、X6-40 暂填 1）/ 方向（正转/反转，X8 与其他关节反向时选反转）；
5. 点列表里的电机选中，右侧出现调试区，状态监控自动开始。

## 第 3 步：开始调试

- **位置控制**：目标角度（0xA4 绝对位置）/ 增量角度（0xA8），V3 旧款自动按「固件多圈角差值」执行；
- **机械零点标定（V3 旧款必做一次）**：通电状态下用位置控制把关节转到凸点对齐 → 「电机基础参数设置」页签点「📌 记录机械零点(E0)」→ 之后发 0° 即回凸点；
- **PID**：「控制参数设置」页签先「读取全部六/七参数」→ 改 → 写 RAM 试 → 写 ROM 固化；
- **限幅**：「控制参数设置」页签顶部「⛔ 限幅与零点」填角度上下限/最大速度/最大电流（改即自动保存），所有控制方式均受其约束，越限自动停止并报警；V4 固件限位（0x20 索引 6/7，系统级写 ROM）在「电机基础参数设置 → 系统功能」页，默认 65535=未设限，仅失能状态可写；
- **实时曲线**：Vofa+ 式智能绘图，任何页签下持续更新；
- **日志**：手动/控制帧（带操作名与报警详情）+ 界面摘要写入 `日志\调试日志_时间戳.txt`（每次运行一个文件；轮询帧自动静默防刷屏，可随时查看你操作了什么、报警原因是什么）。

> 📚 详细操作见 **使用说明.md**。

## 技术要点速览

- **协议混调**：V3.9（旧款 X8/X6）+ V4.3（X6-40）+ V4.4（X2-7），注册表登记协议自动渲染面板；X6-40 已由只读特征自测支持 V4.3，但协议特有写入仍需逐项验证；
- **V3 旧款位置控制（终版定论）**：转子侧单圈绝对值编码器 + 固件多圈角（0x92，D1~4）；0xA4 按多圈目标角差值执行；**E0 标定存凸点固件角（非相位）**——详见技术归档「问题 E」；
- **32 位 Python 3.12**（`E:\Program Files\Python312-32`）+ PyInstaller 6.22 onedir 打包；
- **回归测试**：Node.js + vm 沙箱（无硬件验证协议组帧/解析/UI），脚本思路见 AGENTS.md。

## 常见问题（速查）

| 现象 | 处理 |
|------|------|
| 打开设备失败/被占用 | 先关闭 MYACTUATOR 官方软件、ZCANPRO |
| 扫描不到电机 | 查接线/终端电阻/波特率/24V |
| X8/X6 转不动、PID 全零 | 协议选错或 PID 被清零，见使用说明常见问题 |
| 设 360° 只转 60° | 减速比没填对（X8 填 6、X6-S2 填 36） |
| 断电后电机失联、界面卡死 | 电机断电瞬间拉死总线，拔插 USBCAN 恢复（硬件瞬态，待对照实验定论） |
| 旧电机断电后归零点失效(回不到之前位置) | 硬件决定:V3 旧款无断电记忆,断电期间关节若被移动超过 360°÷减速比(输出轴一圈:X8=60°、X6-S2=10°),圈号丢失,重新上电归零无法回到之前位置;断电调零仅保证该单圈范围内准确 |
