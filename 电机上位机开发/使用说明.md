# 脉塔电机调试上位机 — 使用说明

> 📖 详细操作手册(用户/实验现场阅读);表层入口见 **README.md**,技术路线见 **技术归档.md**,AI 对接见 **AGENTS.md**。
>
> 本上位机可同时调试**两代**脉塔伺服电机:
> - **V3.x 协议**(RMD-X 系列,如 **X8-PRO、X6-S2**)
> - **V4.4 新协议**(最新款,如 X6-40、X2-7)
>
> 界面全中文,电机数量不设上限,每台电机按注册表登记的协议自动渲染对应调试面板。

---

## 一、运行方式(两种任选)

### 方式 A:打包版(推荐,交给用户/实验现场用)

1. 双击运行 `打包上位机.bat`,等待打包完成;
2. 进入 `dist\上位机\` 文件夹,找到 **上位机.exe** 双击即运行;
3. 无需安装任何东西;整个 `dist\上位机` 文件夹可整体拷贝到任意 Windows 电脑使用。

> 首次运行若提示「需要 WebView2 运行时」,按弹窗提示下载安装即可(在线安装包约 2MB,一分钟完成)。

### 方式 B:开发模式(本机调试用)

1. 双击 `启动上位机.bat`;
2. 按提示选择:`1` 真机模式(连接 USBCAN 模块)/ `2` 模拟模式(无硬件预览界面);
3. 本方式需要本机装有 32 位 Python 3.12(路径 `E:\Program Files\Python312-32`)。

## 二、硬件连接

```
电脑 ──USB── 脉塔 USBCAN 模块 ──CAN总线── 电机1、电机2、……(两代协议可混接)
```

1. USBCAN 模块插入电脑 USB 口;
2. CAN 总线按说明书接好:**CAN_H 接 CAN_H,CAN_L 接 CAN_L**,总线两端各配一个 120Ω 终端电阻(多数模块自带开关,短距离调试不开也能工作);
3. 24V 电源接入电机动力线;
4. 打开本上位机,在「🔌 设备连接」卡片选好设备型号与波特率(出厂默认 1M,联调前请核对),点击「打开设备」。

> 💡 **模块自动适配**:脉塔不同批次配的 USBCAN 模块分两种——新 CANFD 系(USBCANFD-200U,类型 41)与老 VCI 系(USBCAN/USBCAN2,类型 3/4)。上位机会**自动逐一尝试打开并回退适配**(老模块自动走经典 CAN 模式与对应的波特率定时器),无需手动区分型号;日志区会明确显示实际打开的类型。

## 三、调试前必读:两代协议差异

> ⚠️ 两代电机**调试流程相同**(都无需使能),但指令字段有差异,务必按注册表登记的协议操作:

| 项目 | V3.x(RMD-X 系列:X8-PRO / X6-S2) | V4.4 新款(X6-40 / X2-7) |
|---|---|---|
| 使能 | **无需使能**,上电后直接发闭环指令 | **无需使能**,上电后直接发闭环指令 |
| 停机后 | 重新发闭环指令即可 | 重新发闭环指令即可 |
| PID 参数 | 六参数 uint8(0~255),**0x30 读全/0x31 写RAM/0x32 写ROM 一次读写** | 七参数 float32,0x30/31/32 按索引读写 |
| 减速比 | **必须填**(X8-PRO 填 6、X6-S2 填 36) | 固件已内置,一般填 1 |
| 加速度 | 索引 0~3(位置加/减速、速度加/减速) | 索引 0~3(同 V3.x) |
| 0x9A 回复 D2 | 保留(无 MOS 温度字段) | MOS 管温度 |
| 0x71 功率 | 在 **D6~7** | 无此指令 |
| 0x79 改编号 | 支持(D7=新 ID 1~32),**命令发往固定地址 0x300、回复也从 0x300 回** | 已删除 → 0x20 索引 0x05 |
| 多圈掉电记忆 | **固件不支持**(转子侧单圈绝对值编码器:相位断电保持、圈号丢失;0x63/0x64 写 ROM 实测无效)→ E0 机械零点档案 + 上电自动归位 | **支持**:0x20 索引 0x04(掉电前自动保存多圈值,重启生效,需失能时写) |
| 转向一致性 | 无全局方向反转指令,由上位机注册表「方向」字段软件映射 | 同左 |
| 多电机 0x280 | 任意指令广播(需先失能编号滤波器) | 任意指令广播(需先失能编号滤波器) |

> ⚠️ **协议选错会损坏电机参数!** 典型事故:在旧版上位机/V2.4 工具里点「读取全部六参数」发 0x31/0x32 帧,在 V3.x 电机里这两条指令是**「写 PID 到 RAM/ROM」**,会把六参数清零、电机不转。**调试前务必确认电机型号对应的协议,在注册表选对协议再操作。**

### V3.x(RMD-X 系列:X8-PRO / X6-S2)标准调试流程

1. 注册表添加该电机,协议版本选 **V3(旧型号)**,**减速比填实际值**(X8-PRO 1:6 填 6、X6-S2 36:1 填 36),**方向选「反转」若该电机正角度旋转方向与其他关节不一致**(典型:X8-PRO 正角度为顺时针、其余电机为逆时针,则 X8-PRO 选「反转」,上位机会自动把该电机所有角度/速度/力矩指令与读数做符号映射);
2. 打开设备 → 扫描在线确认 ID;
3. **无使能环节**——直接在「位置控制」「速度/力矩」页签发闭环指令,电机会立即响应(位置环直接转);
4. PID 在「PID 参数」页签操作:先「读取全部六参数(0x30)」看当前值 → 修改六个输入框 → 「0x31 写 RAM」试效果 → 确认无误再「0x32 写 ROM」永久保存;
5. 抱闸款电机第一次运动前,先在「启停与抱闸」页签发 **0x77 松抱闸**;
6. **旧款为「转子侧单圈绝对值编码器」+ 固件多圈角(0x92)**:断电后转子相位(单圈 0~360°)保持精确,圈号由固件 0x92 维护(会被 0xA8 增量漂移);**0x63/0x64 实测无效**。机械零点用「凸点＋刻线」定位,标定一次 E0(**记录凸点的固件角**)后:位置显示以机械零点为 0°,发 0° 即回凸点;0xA4 绝对位置按多圈目标角直接发送(固件差值执行,任意范围)。标定方法:通电状态下用位置控制指令把关节转到凸点对齐(减速器自锁,勿断电手动推)→ 点「记录机械零点(E0)」;
7. 调试结束发 0x80 关闭。

### V4.4 新款(X6-40 / X2-7)标准调试流程

1. 注册表添加该电机,协议版本选 **V4(新型号)**,减速比填 **1**(X2-7 实测确认:固件已内置减速比,指令角度即末端转轴角,无需再乘系数);方向与其他关节不一致时选「反转」(软件自动映射);
2. 打开设备 → 扫描在线确认 ID;
3. **直接**在「位置控制」「速度/力矩」页签发闭环指令,电机会立即响应;
4. 抱闸款电机第一次运动前,先在「启停与抱闸」页签发 **0x77 松抱闸**;
5. **掉电记忆(推荐开启)**:在「系统」页签点「🔋 开启掉电记忆」,发送 0x20 索引 4 = 1,掉电前固件自动把多圈值存入 FLASH(**重启生效,写入需在电机失能状态下进行**);再次上电多圈位置自动恢复,无需标定;
6. 调试结束发 0x80 失能(或 0x81 停止保持)。

## 四、断电安全规范

> ⚠️ 突然拔电可能造成正在写入的参数丢失或损坏:

1. 断电前先发 **0x80 关闭**(停止输出);
2. 等 3~5 秒,让固件完成状态保存;
3. 再断开 24V 动力电(最后拔 CAN 线)。

## 五、界面功能速览

- **🔌 设备连接**:设备型号(中文模块名,如「USBCANFD-200U(CANFD 新模块)」)/索引/通道/波特率设置,打开关闭设备,总线状态徽章;
- **🤖 电机注册表**:自行添加电机(名称/ID 1~32/协议版本 V3(旧型号)·V4(新型号)/减速比/**方向(正转/反转)**/备注),表格化对齐显示;每行有「编辑」「删除」按钮——编辑可改全部字段(保存修改/取消);列表自动保存到程序目录下「**电机注册表.json**」(exe 同目录),重启后自动载入——电机参数没变可一直使用,无需重新配置;点击条目选中后右侧调试区按该电机协议渲染;「扫描在线电机」**逐 ID 1~32 全总线探测(与注册表无关)**,新接入的未注册电机也能发现并提示添加(发送失败即中止并提示检查上电/接线);**方向字段**:各关节正角度旋转方向不一致时(如 X8-PRO 顺时针、其余逆时针),给方向相反的电机选「反转」,上位机自动把该电机的角度/速度/力矩指令与读数全部做符号映射(列表带 ↺ 标记);
- **🛠️ 电机调试区**(7 个页签,内容随电机协议自动变化):
  - 状态监控:定时轮询温度/电压/抱闸/错误码(逐位中文解释)/力矩电流/速度/位置(**V3 旧型号位置由 0x9C 编码器脉冲累积推算(相对角度),收到非零 0x92 多圈角度时自动校准为绝对角度**;V4 新型号 0x9C 自带角度;V3 旧固件电压恒 0 属正常,显示「固件不回传」;轮询帧不写入收发日志,不刷屏);
  - 启停与抱闸:两代协议均无使能环节,上电直接发闭环指令;0x80/0x81/0x77/0x78;
  - 位置控制:0xA4 绝对位置与 0xA8 增量位置**各有独立输入框**(增量以当前位置为起点);另有 0xA6 单圈位置(带转向,**角度按转子单圈,上限 359.99°÷减速比**,超出发送前自动校验拦截);
  - 速度/力矩:0xA2 速度闭环 / 0xA1 力矩闭环;V4 另有 0xA9 力控位置、0x72/0x73 前馈位置;
  - PID 参数:**V3 旧型号六参数(uint8 0~255,一次读写全六参数)**、V4 新型号七参数(float32,按索引);写 ROM 有二次确认;
  - 编码器与零点:**⚠️ X8-PRO/X6-S2 固件实测不响应 0x60/0x61/0x62/0x63/0x64**(旧款为转子侧单圈绝对值编码器,零点固定在编码器相位 0 不可改写),请用 0x90 单圈编码器/0x92 多圈角度/0x94 单圈角度读取;**V3 页签含「📌 机械零点(E0)标定与归位」块**:通电状态下用位置控制转到凸点对齐 → 点「记录机械零点」存档案(E0=凸点固件角),随时点「🏠 自动回机械零点」一键归位;**V4 新款的 0x64 按钮点一次即自动完成「0x80 失能 → 0x64 写 ROM → 0x76 复位」三步**(协议要求:失能状态下 0x64 才能写入 ROM,写后需复位重启新零点才生效)——失能瞬间电机掉力、关节可能因重力下落,点确认前请先做好机械防护;
  - 系统:🆔 **电机 ID(0x79,发往固定地址 0x300,置顶)**、运行模式 0x70、状态读取(功率/运行时间/固件日期/型号)、保护与复位(0xB3/0x76)、波特率 0xB4、功能控制 0x20;V4 另有 0xB6 主动回复;**V4 系统页含「🔋 掉电记忆(多圈掉电保存)」一键开关(0x20 索引 4,重启生效,需失能时写)**;**V3 系统页含「🔧 掉电位置恢复(旧款 X8/X6,单圈绝对值模型)」块**——旧款为转子侧单圈绝对值编码器 + 固件多圈角(0x92):恢复方案 = 标定机械零点 E0(编码器与零点页,通电转凸点后记录)→ 上电点「🏠 自动回机械零点」→ 位置完全绝对化;

> 📐 **减速比换算**:注册表为每台电机登记减速比后,界面所有角度/速度均为**输出轴**单位(°、dps),发送时自动 ×减速比换算到转子侧、读数自动 ÷减速比还原,力矩电流(A)不换算。状态面板与日志摘要会标注「(输出轴)」。
- **📈 实时曲线**:Vofa+ 式智能绘图——**Y 轴量程随当前窗口数据自动调整**(位置转过 360° 多圈也完整可见,刻度数字精度随量程自适应),**无数据时曲线停留在上一有效值不归零**;坐标轴、时间轴(秒)、鼠标悬停十字线读数;三通道可开关,可暂停/清空;**任何页签下曲线都持续更新**(与状态监控页签无关);
- **🧪 多电机同步(0x280)**:V3/V4 任意指令广播(需先执行 0x20 索引 0x02 失能编号滤波器);
- **✍️ 手动发帧**:任意 ID/0x280 广播 + 十六进制数据,附常用帧快捷按钮;
- **📥 收发日志**:手动操作的全部收发帧带毫秒时间戳与协议解析摘要(状态轮询帧自动静默),可清空;同时程序自动把全部收发记录写入程序目录下 **`日志\` 子文件夹**——**每次运行生成一个独立文件**「调试日志_YYYYMMDD_HHMMSS.txt」(UTF-8),单次运行的记录文本量小、便于按时间定位,供事后查看与分析。

## 六、常见问题

| 现象 | 处理 |
|---|---|
| 打开设备失败,提示设备被占用 | 先关闭 MYACTUATOR 官方软件、ZCANPRO 等其他 CAN 软件,再点打开 |
| 设备列表为空 | 检查 USBCAN 模块 USB 连接与驱动(模块自带驱动盘);重新插拔后点「刷新列表」 |
| 扫描不到电机 | 核对总线接线(CAN_H/CAN_L 是否接反)、终端电阻、波特率是否与电机一致 |
| 打开成功但发送失败(总线上无应答) | 属于总线侧问题:确认电机 CAN 线已接、24V 已供电;核对波特率;检查 CAN_H/CAN_L 是否接反 |
| X8-PRO / X6-S2 转不动,相电流与 PID 全零 | **协议选错了或 PID 被清零**:这两款是 V3.x(RMD-X)协议;若曾在旧版上位机/V2.4 工具里点过「读取全部六参数」,PID 已被清零——用 V3.x 面板「0x31 写 RAM」恢复(参考值:电流KP 100/KI 100 · 速度KP 50/KI 40 · 位置KP 50/KI 50),**或在实验室找同型号健康电机,用 0x30 读出六参数照抄写回**;确认能动后再「0x32 写 ROM」固化 |
| 设 360° 只转 60°(或角度/速度差一个固定倍数) | 注册表里该电机的**减速比没填对**(X8-PRO 填 6、X6-S2 填 36);删除该条目重新添加并填写正确减速比 |
| 正角度旋转方向与其他关节相反(如 X8 顺时针、其余逆时针) | 协议无全局方向反转指令,由上位机软件映射:注册表编辑该电机,**方向选「反转」**——所有角度/速度/力矩指令与读数自动取反,列表带 ↺ 标记;换相线方案对一体化 FOC 电机不可行 |
| 旧款 X8/X6 断电后再上电位置丢失 | **正常现象(单圈绝对值模型)**:断电后转子相位保持精确,圈号由固件 0x92 维护。恢复:①标定机械零点 E0(「编码器与零点」页:通电转凸点→记录机械零点);②上电点「🏠 自动回机械零点」或直接发 0° 回凸点。新款 V4 无此问题:「🔋 开启掉电记忆」(0x20 索引 4)后掉电前固件自动保存多圈值 |
| 0xA6 单圈位置「操作莫名其妙」、电机乱转 | 单圈位置按**转子单圈**工作,输出轴可发范围 = 0~359.99°÷减速比(X8-PRO 1:6 即 0~60°);超范围发送会被上位机拦截并提示,请减小角度或改用 0xA4 绝对位置 |
| 0x60/0x61/0x62 发送后无回复 | **正常现象**:X8-PRO 固件未实现这三条指令;请改用 0x90 单圈编码器 / 0x92 多圈角度 / 0x94 单圈角度 |
| V4 新款 0x64 设零后断电重启还是旧零点 | **协议要求两个生效条件**:①电机**失能**状态下 0x64 才能写入 ROM;②写入后需发 **0x76 复位重启**新零点才加载。直接用「编码器与零点」页的 **0x64 按钮**——已自动按「0x80 失能 → 0x64 写 ROM → 0x76 复位」三步执行(失能瞬间关节可能因重力下落,先做好机械防护);完成后用 0x92 验证多圈角从零起计 |
| 旧款 X8/X6 点 0x64/0x63 无反应 | **正常,固件不支持写 ROM**(0x63/0x64/0x60-62 实测全部无效)。改用「编码器与零点」页 E0 标定:通电转凸点→「记录机械零点」→ 发 0° 即回凸点;位置显示以上位机档案为准 |
| 0x79 修改 ID 无回复/失败 | 0x79 命令发往固定地址 **0x300**(与 0x140+ID 无关);修改前确保总线上只有这一台电机通电,否则多台一起被改;修改后重启电机生效;**实验室旧款 X8/X6 的 ID 由外壳拨杆开关设置,0x79 对拨杆款无效,请直接用拨杆设置 ID** |
| V3/V4 电机不响应广播 0x280 | 需先在该电机「系统」页签执行 0x20 索引 0x02(失能编号滤波器) |
| 修改 ID/波特率后电机失联 | 修改 ID 需重启电机生效;波特率改后需同步调整总线所有设备与上位机 |
| 收发日志被刷屏 | 状态轮询帧已自动静默,不写入收发日志(`日志\` 子文件夹的当次运行文件仍完整记录,供事后分析) |
| 双击 exe 提示缺少 WebView2 | 按弹窗引导在线安装一次即可(仅首台电脑需要) |
| 杀毒软件拦截 exe | PyInstaller 打包程序常见误报,添加信任即可 |
