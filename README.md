# Arm for GO2 — 项目工程使用说明

> 无人平台武器臂工程：脉塔电机调试上位机、ESP32 无线 CAN 中继、协议资料、IMU。
> AI 协作内容统一放在 `AI间交流\`（AI 向约定见项目根 `CLAUDE.md`）。

---

# 📖 第一部分：这是什么

GO2 武器臂的工程总目录，包含四个子领域：

| 子领域 | 目录 | 一句话说明 |
|--------|------|-----------|
| 电机调试上位机 | `电机上位机开发\` | 双协议（V3.9/V4.3/V4.4）脉塔伺服电机全中文 CAN 调试工具，双击 exe 即用 |
| ESP32 无线 CAN | `ESP32 for WiFi and BLE CAN\` | WiFi/BLE 无线 CAN 中继站，三级通道自动降级（STA→AP→USB 串口） |
| 电机协议资料 | `Database\` | 三版中文协议手册（V3.9/V4.3/V4.4）与产品资料 |
| IMU | `IMU_HI12S2-MI1\` | 精浦 HI12S2-MI1（串口+CAN），枪口端与基座端各一个 |
| AI 协作 | `AI间交流\` | 情报/记录/消息，让未参与对话的 AI 同步项目情报 |

---

# 📖 第二部分：新用户操作

1. **跑上位机**：双击 `电机上位机开发\dist\上位机\上位机.exe`（详细操作见该目录 README 第一部分）；
2. **用 ESP32 无线 CAN**：编译下载一次 + 首次网页配 WiFi 一次，之后全自动（详见 `ESP32 for WiFi CAN Custom\README.md` 第一部分）；
3. **协议手册**：`Database\电机\`（三版中文协议）；结构图纸在 `E:\Work and Study Project\无人平台武器臂\模型\`。
