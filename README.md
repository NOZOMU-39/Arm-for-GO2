# 📖 第二部分：新用户操作

1. **跑上位机**：双击 `电机上位机开发\dist\上位机\上位机.exe`（详细操作见该目录 README 第一部分）；
2. **跑交互界面**：`机械臂操作交互界面\`（USB/无线双通道，详见该目录 README 第一部分）；
3. **用 ESP32 无线 CAN**：编译下载一次 + 首次网页配 WiFi 一次，之后全自动（详见 `ESP32 for WiFi and BLE CAN\ESP32 for WiFi CAN Custom\README.md` 第一部分）；
4. **协议手册**：`Database\电机\`（三版中文协议）；结构图纸在项目内 `武器臂三维模型\模型\`。

### 让 AI 接手工作（交接协议）

每个 AI 对话都是独立的，交接机制让旧对话退休、新对话无缝接手——任何 AI 工具（DSH / Claude / Codex 等）都认 `AGENTS.md`。

**什么时候需要交接**：对话快到上下文上限 / 想换 AI 工具 / 隔天隔周继续某领域。

**交接三步**：
1. **旧对话留文件**：对旧对话说「写交接文件退休吧」——它在 `AI间交流\交接\交接_领域_日期.md` 写四段式（现状/待办/下一步/踩坑）并提交；旧对话已结束也没关系，新对话读 AGENTS.md + 情报即可接上；
2. **一句话发起**：新对话第一句说「让新对话接手〔领域〕的〔任务〕，旧对话退休，走交接协议」；
3. **确认接手**：新对话先汇报「已接手〔领域〕：现状…待办…下一步…」，你点头它才开工；验收/审查类任务默认先报现象方案，不擅自改代码。

**交接完成后**：交接文件（短期）确认无遗漏后，你说「交接里 XX 可以删了」→ 它删；情报（长期）分册只**替换**不追加（`情报.md` 是目录页，内容是 `情报\` 下的分册，历史进 `99_变更记录.md` 与 git），更新前会先问你确认；历史变更查 `git log --oneline`。

> 完整协议见项目根 `AGENTS.md`「对话交接协议」；交接文件模板在 `AI间交流\交接\交接模板.md`。
