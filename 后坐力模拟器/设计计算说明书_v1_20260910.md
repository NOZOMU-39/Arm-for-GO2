## 第 1 章 设计任务书

### 1.1 设计目标

设计一台安装于机械臂末端的后坐力模拟器，以机电方式产生半自动手枪级的**力-时间历程**（不是单一冲量，见 1.4 修正），为后坐扰动抑制与动态射击工作空间研究提供可重复、可标定、无实弹的扰动激励源[7]。

**在研究中的定位（2026-09-23 用户定稿主旨）**：

> 让四足上的机械臂能带着手枪级后坐连续射击，把枪口偏移和关节载荷压在一个预算内，并给出"姿态、接口、控制器"三个量的设计规则。

据此，本装置的定位是研究链条的第①环（扰动源），它不承担另外两环：第②环是平台层（射击姿态 + 枪与法兰之间连接件的软硬，即"动态射击工作空间"），第③环是控制器（预算内抑制瞬态 + 事后收回瞄准点）。三个量互相牵制（姿态好可能不好瞄、接口软则枪口位移大、控制器强则允许更硬的接口），中间的折中空间即研究内容。

**接口的定义（本说明书用词）**：枪/模拟器与机械臂末端法兰之间的连接件（现有构型为"法兰 → 末端云台"，刚性直连）。其软硬决定峰值力按什么倍率传进关节：由能量关系，弹性接口的 `峰值力 × 单边行程 = 2 × 器件动能`（器件 1.6 kg、速度 1.6 m/s 时约 4.2 J），行程做到单边 20 mm、等效刚度 10 到 20 N/mm 时，传到关节的峰值力约 210 N（刚性直连为枪自身峰值 875 到 1167 N）。此件属平台层，不属本装置。

### 1.4 系统工作原理（设计构思）

以"**力-时间历程等效**"为原理（2026-09-23 修正，取代原"动量等效/向机架输出冲量 I = m·v"的表述）。

**修正后的机架受力账（取后坐方向为正，一个发射循环）**：

- **加速段（阶段 2）**：击发弹簧推动运动组件向后，其反作用同时顶机架向前。设运动组件行程 S = 21.99 mm、质量 m = 0.834 kg、终速 v = 3.12 m/s，则该段机架受力为

```
F₁(t) = −k·x(t)，峰值 −369 N，持续 T = (π/2)·√(m/k) = (π/2)·√(0.834/16770×1000) = 11.1 ms
该段冲量 = −m·v = −2.60 N·s（向前，与后坐方向相反）
```

- **刹停段（阶段 4）**：缓冲器与弹力弹簧顶机架后墙，向后，冲量 +2.60 N·s（即原说明书所称"那一记"，与参考曲线峰B 875 N/3.5 ms 同档）。
- **回程与越位段**：弹力弹簧推回组件时反作用向后 +1.33 N·s，组件压回击发弹簧时反作用向前 −1.33 N·s。

**结论（牛顿第三定律，本设计的硬约束）**：整机为封闭系统，运动组件起止均静止，故**一个完整循环内机架受到的净冲量恒为 0**（−2.60 + 2.60 + 1.33 − 1.33 = 0）。真枪之所以有净冲量，是因为弹丸与燃气离开系统带走了动量（5.8mm 约 1.75、9mm 约 2.8 N·s）。**本装置复现的是后坐中的内部往复撞击分量（与气动仿真枪同类，其净冲量仅约真枪的 2%），不产生净冲量**——因此本装置定位为"后坐力-时间历程激励源"，不称"冲量生成器"；论文与对外表述一律按此，详见 §9 修正条。

参数分层：

1. **扰动层**：力-时间历程 F(t)——决定"打多重、打多急"；其中刹停段峰值与脉宽对标真枪主脉冲；
2. **储能层**：击发弹簧 E = ½kS²——决定速度与行程；
3. **时序层**：不完全齿轮（半齿轮）+ 齿条——每圈一发，齿缺段几何脱啮释放；
4. **动力层**：DM-S2325-1EC 伺服——装填与节奏控制；
5. **缓冲层**：SMC RB1007 液压缓冲器并联弹力弹簧——决定脉冲形状与峰值。

## 第 2 章 工况分析与载荷性质

### 2.1 单发工作循环（时序）

| 阶段 | 动作 | 时长量级 | 载荷特征 |
|---|---|---|---|
| 1 装填 | 半齿轮啮合齿条，推动运动组件压缩击发弹簧 21.99 mm | 100 ms（4 Hz）至任意慢（单发） | 齿条推力 0 → 369 N 线性增长 |
| 2 释放 | 齿缺段到达，齿条与齿轮脱开，组件被弹簧弹射 | 约 11.1 ms（加速段）**2026-09-23 修正**：原写 7 ms 系误按 S/v 计算；正确值为四分之一振动周期 T = (π/2)√(m/k)，代入 m = 0.834 kg、k = 16.77 N/mm（ω = √(16770/0.834) = 141.8 rad/s）得 T = 11.1 ms | 弹簧力 369 N → 0 |
| 2b **加速段反作用（2026-09-23 补）** | 击发弹簧反作用顶机架向前 | 与阶段 2 同时，11.1 ms | 机架受力 369 N → 0（向前），冲量 −2.60 N·s |
| 3 飞行 | 组件自由飞行至撞击缓冲器 | 约 2 ms | 惯性 |
| 4 缓冲 | RB1007 与弹力弹簧并联吸收 4.05 J，刹停并回弹 | 3 到 5 ms | 峰值 950 到 1400 N 级 |
| 5 回位 | 弹力弹簧推组件回静止位 | 15 到 20 ms | 二次冲击 0.6 到 1.1 J |

### 2.2 载荷性质认定（用于强度取值的依据）

- **单向性**：全部机构单向旋转、单向受力（齿轮单向啮合、齿条单向推进、弹簧单向压缩），**无交变（对称循环）载荷**——齿轮齿根弯曲按脉动循环取值；齿面接触应力为恒压性质（点蚀与旋转方向无关），寿命按循环次数取系数；
- **载荷谱**：每次装填一次完整加载-卸载（0 → 峰值 → 0），属**脉动循环**；循环次数 N = 设计寿命 = 2×10⁴；
- **冲击性质**：装填为伺服位置模式可控斜坡（力从零线性爬升），仅逐齿进入啮合时有微小冲击——使用系数 KA 取 1.1（平稳驱动偏轻微冲击档）[1][2]；
- **速度水平**：节圆线速度 0.23 m/s（极低速）——动载系数 KV 取 1.05（8 级精度低速区）[1][2]。

### 2.3 设计寿命与降额依据

模块化台架使用强度摸底：课题周期内实验量 1 到 2 万发量级。按 N = 2×10⁴ 取接触寿命系数 ZN = 1.55、弯曲寿命系数 YNT = 1.6（调质钢档）[1]，使材料与尺寸选择贴合真实需求（若按 10⁶ 级寿命取值将导致结构尺寸与材料等级虚高，届时报废浪费）。

## 第 3 章 冲量与储能链设计计算

### 3.1 冲量-质量-速度的分配（计算项目 1）

**已知**：I = 2.6 N·s。

**公式**（动量定理与动能定理[1]）：

```
I = m·v                                    ……(3-1)
E = ½·m·v² = I²/(2m)                       ……(3-2)
```

**分析**：由 (3-2)，冲量 I 固定时，组件质量 m 越小所需动能 E 越大，而 E 全部由击发弹簧提供并全部由缓冲器吸收——故 m 的取值受"缓冲器吸能上限"与"齿轮-行程离散约束"共同限制。

**初选**：取 m = 0.80 kg（轻量化初值）：

```
v = I/m = 2.6/0.80 = 3.25 m/s
E = ½×0.80×3.25² = 4.23 J
```

**结果**：初选工作点 v = 3.25 m/s、E = 4.23 J（后经 3.3 节离散约束修正为 834 g / 3.12 m/s / 4.05 J）。

### 3.2 击发弹簧的储能需求（计算项目 2）

**公式**（压缩弹簧储能[1]）：

```
E = ½·k·S²                                 ……(3-3)
```

其中 k 为弹簧刚度（N/mm），S 为压缩行程（mm），E 单位 N·mm = 10⁻³ J。

**选型（标准件）**：选用 TF 系列模具弹簧（轻小负荷级，等载荷分级标准件[4]），目标规格"外径 27、内径 13.5、自由长 70"，由 3.3 节行程约束反推需 k ≈ 16.77 N/mm。

**选型依据**：模具弹簧按"外径 × 自由长 × 载荷等级"查表（等载荷分级原理：同一外径最大载荷标准化，刚度随自由长变化），免除逐件定制与材料试验[4]。

### 3.3 行程的离散约束与最终工作点确定（计算项目 3，本设计关键修正）

**约束来源**：装填机构为不完全齿轮驱动齿条，齿缺边界必须落在齿谷，齿条行程只能取完整齿数的整数倍：

```
S = n·π·m                                  ……(3-4)
```

n 为完整啮合齿数（整数），m 为齿轮模数（标准系列值）。

**反推链**：S → E = ½kS²（式 3-3）→ m = I²/(2E)（式 3-2）。在组件质量窗口 0.75 到 1.0 kg 内枚举标准模数：

| 模数 | 完整齿数 n | 行程 S（mm） | 能量 E（J） | 反推质量 m（kg） | 判定 |
|---|---|---|---|---|---|
| m1.0 | 6 | 18.85 | 2.98 | 1.135 | 质量超窗 |
| **m1.0** | **7** | **21.99** | **4.05** | **0.834** | **窗口内唯一解 ✓** |
| m1.0 | 8 | 25.13 | 5.30 | 0.638 | 超窗，且缓冲占比 90% 过紧 |
| m1.25 | 5 / 6 | 19.63 / 23.56 | 3.23 / 4.66 | 1.046 / 0.726 | 均出窗 |
| m1.5 | 4 / 5 | 18.85 / 23.56 | 2.98 / 4.66 | 1.135 / 0.726 | 均出窗 |

**修正动作**：初选 800 g / 22.4 mm 作废，改按 m1.0 × 7 齿定案。

**定案（计算项目 3 结果）**：

```
S = 7 × π × 1.0 = 21.99 mm
E = ½ × 16.77 × 21.99² = 4054 N·mm = 4.05 J ………(代入式 3-3)
m = I²/(2E) = 2.6²/(2×4.05) = 0.834 kg ………(由式 3-2 反推)
v = I/m = 2.6/0.834 = 3.12 m/s ………………(式 3-1)
```

**结论**：组件设计质量 **834 g**、行程 **21.99 mm**、每发储能 **4.05 J**、撞击速度 **3.12 m/s**。组件实称在 0.75 到 1.0 kg 内时行程不变、冲量随实称标定：I = √(2·E·m实)，834 g 时恰 2.6 N·s，800 g 时 2.55 N·s，1.0 kg 时 2.85 N·s（±10% 内）。

### 3.4 击发弹簧校核（计算项目 4）

**弹簧参数**（TF 系列模具弹簧，用户目视确认商家规格表[4]）：外径 27、内径 13.5、自由长 FL = 70、刚度 k = 16.77 N/mm、密着高 31.5、100 万次档额定压缩量 28 mm / 额定负荷 470.7 N。

**校核项目与代入**：

1. **工作压缩量对额定值**（标准件按厂家额定值校核[4]）：

```
S/额定压缩 = 21.99/28 = 78.5% < 100% ✓
```

2. **工作负荷对额定负荷**：

```
F = k·S = 16.77 × 21.99 = 369 N
F/额定负荷 = 369/470.7 = 78.4% < 100% ✓
```

3. **压缩率对寿命线**（模具弹簧 100 万次寿命线为自由长的 40%）：

```
压缩率 = S/FL = 21.99/70 = 31.4% < 40% ✓
```

4. **密圈校核**（压缩后不得压并）：

```
压缩后长度 = FL − S = 70 − 21.99 = 48.01 mm > 密着高 31.5 mm ✓
```

5. **储能校核**：E = ½kS² = 4.05 J（与 3.3 节需求一致 ✓）。

6. **疲劳寿命**：弹簧额定寿命档为 100 万次（厂家 100 万次规格），设计需求 2×10⁴ 次，为额定的 2%，疲劳余量充足 ✓。

**结论**：击发弹簧 TF27 在工作点 21.99 mm / 369 N 下各项均低于标准件额定值，满足强度与寿命要求（不等式：S < S额、F < F额、压缩率 < 40%、压缩后长度 > 密着高）。

### 3.5 击发弹簧装配条件（设计输出）

- **释放点**：每发从满压缩位 21.99 mm 处释放，该点由装填行程的几何终点确定（见第 5 章释放边界指标），逐发重复；
- **预压**：允许从自由长零力起压缩（标准工况，规格额定即按自由长计）；静止态微预压 0 到 0.5 mm（静力 0 到 8 N）——预压的唯一作用是消除装填起始空程，不承担定位、不参与能量标定；
- **端部处理**：弹射侧回弹敲击由端部垫片（聚氨酯垫圈）处理，指标为不对冲量与逐发一致性造成可测影响。

### 3.6 弹力弹簧（缓冲侧）设计计算（计算项目 5）

**功能需求**：与 RB1007 并联装在运动组件上，承担三项职责——①静止定位（把组件推贴静止基准）；②缓冲起点确定（力从预压位起算）；③撞击刹停兜底（阻尼不足时补足能量吸收）与停后回位。

**选型**：TF 系列模具弹簧 外径 22、内径 11、自由长 35、刚度 22.46 N/mm（用户目视确认[4]），**两根并联**。

**并联刚度**（弹簧并联刚度叠加[1]）：

```
k总 = 2 × 22.46 = 44.9 N/mm ………………(式 3-5)
```

**校核项目与代入**：

1. **全行程压入力对单根额定值**：

```
单根压入力 = k·S = 22.46 × 7 = 157 N < 额定 313.8 N ✓
两根合计 = 44.9 × 7 = 314 N
```

2. **压缩率**（额定压缩 14 mm，寿命线按 40% 自由长 = 14 mm）：

```
压缩率 = 7/35 = 20% < 40% ✓
```

3. **密圈校核**：

```
压缩后单根长度 = 35 − 7 = 28 mm > 密着高 15.8 mm ✓
```

4. **预压与静止力**：

```
预压 0.5 到 1.0 mm → 静力 = 44.9 × (0.5 到 1.0) = 22 到 45 N
```

该静力把组件推贴静止基准（静止基准由用户结构的齿条啮合位或限位承担，见第 8 章解耦条件）。

5. **刹停兜底作用**（能量核算，与第 4 章联算）：组件撞入时，弹力弹簧从预压位继续压缩，参与刹停的能量吸收为 ½k[(x₀+s)²−x₀²]；若无此弹簧，缓冲阻尼偏低档时刹停深度将超 7 mm 行程（见 4.2 对照行）——**弹力弹簧为必需件，不可取消**。

**结论**：两根 TF22 并联（总刚度 44.9 N/mm）在工作行程 7 mm 内各项均低于额定值，满足强度与寿命要求。

### 4.2 刹停能量核算（计算项目 7，缓冲行程验证）

**模型**：运动组件以 v 撞入，并联缓冲链（RB1007 + 弹力弹簧 k总 = 44.9 N/mm，预压 x₀ = 1 mm）共同吸收动能直至停止。设阻尼器在刹停过程中平均阻力为 Fd（速度型阻尼，取档位区间计算），刹停深度 s，则能量守恒：

```
E = Fd·s + ½·k总·[(x₀+s)² − x₀²]          ……(4-1)
展开：E = Fd·s + ½k总·s² + k总·x₀·s
```

代入 E = 4050 N·mm、k总 = 44.9、x₀ = 1，解一元二次方程 ½k总·s² + (Fd + k总x₀)·s − E = 0：

| 阻尼平均阻力 Fd | 刹停深度 s | 行程余量（7 − s） | 停点弹簧储能 | 回弹速度 v回 = √(2W/m) |
|---|---|---|---|---|
| 500 N | 5.97 mm | 1.03 mm | 1.07 J | 1.60 m/s |
| 650 N | 5.02 mm | 1.98 mm | 0.79 J | 1.38 m/s |
| 840 N | 4.14 mm | 2.86 mm | 0.57 J | 1.17 m/s |

**对照（无弹力弹簧）**：500 N 档刹停深度 = E/Fd = 8.1 mm > 7 mm **打底**——证明弹力弹簧为刹停兜底必需件（设计依据留痕）。

**结论**：预期实际阻尼处于 650 到 840 N 档（3.1 m/s 高速端速度型阻尼力偏大），行程余量 2.0 到 2.9 mm，**组件停稳前缓冲器不得到底**——该条列为台架第一验收项（验收方法：测杆剩余露出量）。

### 4.3 缓冲峰值力估算（计算项目 8，框架载荷输入）

**恒力下限**（理想恒力缓冲的最小峰值[1]）：

```
F恒 = E/d = 4050/7 = 579 N                   ……(4-2)
```

实际液压缓冲器为速度型阻尼，初段速度高（3.12 m/s）时阻力高于平均值，峰值估 950 到 1400 N 级。手册无最大阻力字段，**峰值实测定稿**；框架按 2000 N 短脉冲校核，余量充足。

### 4.4 脉宽计算（计算项目 9）

匀减速模型（保守上限）：

```
t = 2·d/v = 2 × 7/3.12 = 4.5 ms（全行程上限）
按实际刹停深度 4.1 到 5.0 mm：t = 2.6 到 3.5 ms
```

**结论**：脉冲宽度 2.6 到 4.5 ms，与真枪主脉冲（5 到 8 ms 全事件，主峰约 3.5 ms）[2][6] 同档——参考曲线主峰 3.5 ms 即此对标。

### 4.5 回弹与二次冲击（计算项目 10）

刹停点弹力弹簧储能释放，组件回弹速度 1.2 到 1.6 m/s（表 4.2），对应二次冲击能量：

```

```

### 4.6 弹力弹簧刚度敏感性（修正计算，计算项目 11）

对 k 取档复算（式 4-1 同法），判据：500 N 保守阻尼档余量 ≥1.5 mm 且回弹 ≤1.4 m/s 时最优；由 834 g 基准复算得 k = 44.9 时余量 1.03 到 2.86 mm、回弹 1.17 到 1.60 m/s——**定案沿用 44.9（两根 TF22 现货）**；若台架实测阻尼均值跌破 650 N，执行兜底预案：加第三根 TF22（k = 67.4），500 N 档余量回升至约 1.4 mm。

## 第 6 章 轴系设计计算

### 6.1 半齿轮轴（B 轴，贯穿 B 齿轮与半齿轮）（计算项目 17）

**结构**：Φ6 圆轴，一端装 B 传动齿轮（Φ6 孔），中部装半齿轮（Φ6 孔），两端轴承座支承；承受转矩与啮合径向力。

**载荷计算**：

```
转矩（由 5.1）：T = 3321 N·mm
半齿轮-齿条啮合径向力：Fr₁ = Ft₁·tanα = 369 × tan20° = 134.3 N
A-B 啮合径向力（取 z30 档）：Fr₂ = Ft₂·tanα = 221 × tan20° = 80.4 N
保守合成（两力方向不同仍代数相加）：Fr = 134.3 + 80.4 = 214.7 N   ……(6-1)
```

**修正（2026-09-23，重要）**：上式只取了两个啮合点的**径向**分力，漏掉了同样垂直于轴线、且量值更大的**切向**分力。按啮合点合力计算：

```
齿条副合力 = √(Ft₁² + Fr₁²) = √(369² + 134.3²) = 392.7 N
A-B 副合力 = √(Ft₂² + Fr₂²) = √(221² + 80.4²) = 235.2 N
两力作用在轴上不同轴向位置、方向随布局组合，合成横向载荷 = 300 到 570 N（按布局定）
=> 实际载荷为原取值 214.7 N 的 1.4 到 2.7 倍
```

按修正载荷（取 570 N）复核弯扭合成：

```
M = 570 × 60/4 = 8550 N·mm
σca = √(M² + (αT)²)/W = √(8550² + (0.6×3321)²)/21.2 = 8768/21.2 = 414 MPa
40Cr 的 [σ-1] = 340 MPa => S = 0.82（小于 1，不合格；原称 S = 1.90 有误）
定：Φ6 轴不满足，需升 Φ8（W = 50.3 mm³ => σca = 174 MPa，S = 1.95 ✓）或把轴承跨距由 60 mm 缩到 40 mm（M = 5700 N·mm => σca = 277 MPa，S = 1.23，偏紧）。**若按 5.8mm 档（载荷减半）重算，Φ6 可保。**
```

**弯矩估算**（轴承跨距按结构预估 L = 60 mm，危险截面按跨中简化）：

```
M = Fr·L/4 = 214.7 × 60/4 = 3221 N·mm                    ……(6-2)
```

**截面模量与应力**：

```
抗弯截面模量 W = π·d³/32 = π × 6³/32 = 21.2 mm³          ……(6-3)
弯曲应力 σb = M/W = 3221/21.2 = 152 MPa                   ……(6-4)
抗扭截面模量 Wt = π·d³/16 = 42.4 mm³
扭转剪应力 τ = T/Wt = 3321/42.4 = 78.3 MPa                ……(6-5)
```

**弯扭合成校核**（脉动循环，折合系数 α = 0.6[1]）：

```
当量弯矩 Mca = √(M² + (αT)²) = √(3221² + (0.6×3321)²)
             = √((10.37 + 3.97)×10⁶) = 3788 N·mm          ……(6-6)
当量应力 σca = Mca/W = 3788/21.2 = 178.6 MPa              ……(6-7)
```

**材料选择与结论**：

```
40Cr 调质：许用对称弯曲疲劳应力 [σ-1] ≈ 340 MPa → S = 340/178.6 = 1.90 ✓
45#/S45C 调质：[σ-1] ≈ 200 MPa → S = 1.12（贴线，不推荐）
定：半齿轮轴 Φ6、40Cr 圆棒（调质），S = 1.90，满足强度要求。
```

**刚度校核**（简支梁跨中挠度）：

```
f = Fr·L³/(48·E·I)，I = π·d⁴/64 = 63.6 mm⁴，E = 2.06×10⁵ MPa
f = 214.7 × 60³/(48 × 2.06×10⁵ × 63.6) = 0.074 mm
（**2026-09-23 修正**：原写 0.012 mm 系计算错误，重算为 0.074 mm）
许用挠度 [f] ≈ (0.0003 到 0.0005)·L = 0.018 到 0.030 mm → f > [f]，**不满足**
按修正载荷 570 N：f = 570 × 60³/(48 × 2.06×10⁵ × 63.6) = 0.196 mm，更不满足
=> 刚度是控制条件：Φ8（I = 201 mm⁴）时 f = 0.062 mm（570 N）仍偏大；把跨距缩到 40 mm 时 Φ6 为 0.058 mm（570 N）、Φ8 为 0.018 mm ✓。**设计动作：缩短轴承跨距并（或）升轴径。**
```

### 6.2 2325 输出轴（计算项目 18）

## 第 8 章 装配条件与验收指标

1. 机架后墙固定受力板；RB1007 本体与两根弹力弹簧都装在运动组件上、杆尖与弹簧端朝后顶受力板，三者并联。轴线平行于运动方向。

面向无人平台后坐扰动抑制研究的、安装于机械臂末端的全电动手枪级后坐冲量等效发生器：以"弹簧活塞动量等效真实枪械后坐冲量"为原理，以"连续单向旋转不完全齿轮每圈一发几何脱啮释放"为时序方案，以"液压缓冲器并联弹簧（组合缓冲）"控制脉冲形态，以伺服编码器相位实现每发释放时刻的确定性同步。

## 第 12 章 5.8mm 轻量档参数重算（2026-09-23 定档，评审基准改以本章为准）

### 12.1 定档依据与目标工作点

**定档**：对标弹种定为 5.8×21mm 手枪弹（92式 5.8mm 手枪）。其单发冲量按 §1.2 修正条推导为 1.75 N·s（弹头 3.0 g × 480 m/s = 1.44 N·s + 燃气约 0.31 N·s；物理上限 1.86 N·s）。原 2.6 N·s（实为 9mm 档）作废；第 1 到 11 章的推导保留作历史留痕，凡与本章冲突处以本章为准。

**工作点**（撞击速度保持不变，以沿用缓冲器工作点与脉宽量级）：

```
v = 3.12 m/s（沿用 §3.3，不由本章重选）
m = I/v = 1.75/3.12 = 0.561 kg
E = ½·m·v² = ½ × 0.561 × 3.12² = 2.73 J                     ……(12-1)
校核：E = I²/(2m) = 1.75²/(2 × 0.561) = 2.73 J ✓
```

**组件质量窗（修正）**：0.50 到 0.70 kg，设计点 561 g。实称在窗内时行程与储能不变、冲量随实称标定（E 固定时 I = √(2Em)）：

```
0.50 kg  => I = √(2 × 2.73 × 0.50) = 1.65 N·s
0.561 kg => I = 1.75 N·s（设计点）
0.70 kg  => I = √(2 × 2.73 × 0.70) = 1.95 N·s
```

**结论**：设计点 v = 3.12 m/s、m = 561 g、E = 2.73 J、单发向后冲量 1.75 N·s。

### 12.2 击发弹簧（两根并联，中间让位给阻尼器）

**本构型（2026-09-23 用户定）**：击发弹簧为两根并联；弹力弹簧（缓冲侧）同样为两根；**阻尼器布置在中间**（位于两组弹簧之间、落在反坐力轴上）。并联刚度叠加；合力作用于轴线上，两根弹簧左右对称，推力对称、消除单簧偏心。行程仍由齿轮整齿离散约束锁定为 S = 21.99 mm（§3.3，不变）。

**总刚度需求**：

```
k总 = 2E/S² = 2 × 2730 / 21.99² = 5460 / 483.6 = 11.29 N/mm     ……(12-2)
每根刚度 = 11.29 / 2 = 5.65 N/mm
总峰值力 = k总 · S = 11.29 × 21.99 = 248 N（每根 124 N）
```

**选型要求**（现货标准件；具体商家行号由用户目视确认后代入校核，本文件不代选）：

- 每根刚度 5.65 N/mm 量级；外径不超过 20 mm（两根并排 40 mm 量级，须落在活块宽度内）；自由长 70 到 100 mm 量级；
- 校核项（按 §3.4 同法逐项代入）：工作压缩 21.99 mm 对厂家额定压缩量 ≤ 100%；压缩率 21.99/FL ≤ 40%（100 万次寿命线）；压缩后长度 > 密着高；储能校核 E = ½ k总 S² = 2.73 J ✓。

**装填载荷联动**：

```
齿条峰值推力 = k总 · S = 248 N
电机端峰值扭矩 = 248 × 9 / 1000 ÷ 0.9 = 2.23 / 0.9 = 2.48 N·m = 峰值能力 5.0 N·m 的 50%
推程平均扭矩 = 124 × 9 / 1000 ÷ 0.9 = 1.24 N·m = 额定 1.35 N·m 的 92%
```

### 12.3 弹力弹簧（两根，与阻尼器并联）

沿用 2× TF22（外 22 / 内 11 / 自由长 35 / 刚度 22.46，并联 44.9 N/mm）：

```
静止静力（预压 0.5 到 1.0 mm）= 44.9 × (0.5 到 1.0) = 22 到 45 N（定位与静止基准，同 §8.5）
工作压缩（刹停终点 ≤ 4.3 mm，见表 12.4）单根 ≤ 22.46 × 5.3 = 119 N < 额定 313.8 N ✓
```

**与 2.6 档的差别（重要）**：轻量档下阻尼器单独即可完成刹停（对照见 12.4），弹力弹簧**不再被"刹停兜底"这一个要求绑住刚度**——但它仍是必需件，三项职责一项都不能省：

1. **静止定位**：把运动组件顶在静止基准（齿条啮合位/限位）上，否则静止位无定义、RB1007 杆的 0 到 1 mm 间隙也无法保持；
2. **缓冲起点确定**：预压 0.5 到 1.0 mm，给出刹停的起始力与位置；
3. **停后回位**：把组件从停点推回静止位（停点处需克服导轨摩擦 20 到 30 N 与 RB1007 内部弹簧 4.2 到 6.9 N），使下一发能被齿条捕获。

**刚度选择因此变成自由项（可选更软）**：若把弹力弹簧也选成与击发弹簧同规格（每根 5.65 N/mm，两根并联 11.3 N/mm），则全机 4 根同规格弹簧（采购与备件简化），并带来三项好处——回弹速度由 1.25 降到 0.88 m/s、二次冲击占比由 22% 降到 8% 量级、静止压紧力可调低（1 到 2 mm 预压给 22 到 45 N，仍满足 §8.5）；刹停深度按 12.4 同法复算为 4.74 mm（500 N 档），仍在 7 mm 行程内（余量 2.26 mm）。原 2× TF22（44.9 N/mm）方案仍可用，不是错，只是偏硬、回弹偏大。

**关于"能否省掉弹力弹簧、只靠 RB1007 内置复位弹簧"（2026-09-23 用户提问，同日实测修正）**：

**实测事实（用户 2026-09-23，实物）**：①活块与滑轨之间加了**直线滚子**，摩擦可忽略；②实物**确实能自行回弹到位**；③目前齿轮与齿条**处于脱啮状态**，无啮合摩擦。据此修正如下。

1. **回位力够（本条修正撤销）**：原判"内置弹簧 4.22 到 6.86 N 推不动 20 到 30 N 摩擦"不成立——滚子导向下摩擦可忽略，4 到 7 N 足以把 561 g 组件推回（实物已验证）。回程时间按 a = 7/0.561 = 12.5 m/s²、行程约 4 mm 估算约 25 ms，4 Hz（250 ms/周期）内充裕。
2. **但静止定位仍需要正向压紧力**：内置弹簧只在杆被压缩（顶住受力板）时对外出力；静止态杆尖留 0 到 1 mm 间隙（§8.2 禁预压杆），此时它的力在阻尼器内部自平衡，**对组件无净作用**。滚子导向摩擦可忽略，于是组件在"杆间隙 + 齿条游隙"区间内**只受重力与惯性支配**：按极限姿态（轨道竖直）组件自重分量 561 g × 9.81 = 5.5 N，远大于滚子滚动阻力（约 1 N 量级）——**组件会沿轨道滑动**，或压向受力板（违反禁预压杆、Φ3 杆偏载会弯），或滑向静止基准。所以仍需要一个**小的**定位压紧力。
3. **兜底职责改由缓冲器档位承担**：无（或极软）弹力弹簧时，刹停能量全部由 RB1007 吸收，低阻尼档会逼近行程极限（500 N 档 5.46 mm、400 N 档 6.83 mm、行程 7 mm）——**必须把阻尼档下限控制在平均阻力 ≥ 450 N 量级**，此项列入第 9 章与台架验收。

**由此得到的定位压紧力需求（取代原"k×预压 ≥ 摩擦阻力"判据）**：

```
要求：静止压紧力 > 重力/惯性分量（极限姿态 5.5 N）+ 余量 => 取 10 到 20 N
取 k = 11.3 N/mm（两根并联，与击发弹簧同规格）=> 预压 1 到 2 mm（静止静力 11 到 23 N）✓
取 k = 5.65 N/mm（单根，或与外径 16 到 20 的软簧等效）=> 预压 2 到 4 mm（11 到 23 N）✓
```

**附带收益（对本装置输出有利）**：弹力弹簧选软或取消后，停点储能由原来的 0.31 到 0.60 J 降到 0.04 J 量级，**二次冲击从 22% 降到 1 到 2%**，输出变成"一记干净向后的撞击 + 一次缓慢回位"，比原来更接近真枪（真枪复进也是缓慢的）。**因此"选软甚至取消弹力弹簧"对本装置的保真度是加分项**，前提是补上第 2 条的定位压紧力（可用小弹簧、磁吸定位或让齿轮/齿条在静止态保持啮合由伺服保持位置，三者择一；其中"靠伺服保持"会引入断电即失位的问题，需一并考虑）。

**结论**：弹力弹簧可**大幅选软（5 到 11 N/mm 量级）**，且越软对输出保真度越好；完全取消则必须解决静止定位（抗重力滑动）与缓冲器档位下限两件事。

### 12.4 刹停与回弹重算

E = 2730 N·mm、k总 = 44.9 N/mm、预压 x₀ = 1 mm，解一元二次方程 ½k总·s² + (Fd + k总·x₀)·s − E = 0：

| 阻尼平均阻力 Fd | 刹停深度 s | 行程余量（7 − s） | 停点弹簧储能 | 回弹速度 v = √(2W/m) |
|---|---|---|---|---|
| 500 N | 4.26 mm | 2.74 mm | 0.60 J | 1.46 m/s |
| 650 N | 3.53 mm | 3.47 mm | 0.44 J | 1.25 m/s |
| 840 N | 2.88 mm | 4.12 mm | 0.31 J | 1.06 m/s |

**对照（无弹力弹簧）**：500 N 档 s = E/Fd = 2730/500 = 5.46 mm < 7 mm ✓ —— **轻量档下阻尼器独立可刹停、不得到底**（2.6 档"必须靠弹力弹簧兜底"的结论在轻量档不再成立，设计自由度增加）。

**二次冲击**：0.60/2.73 = 22% 量级（同 §4.5），台架实测为准。

### 12.5 缓冲峰值与脉宽（需调档）

同一缓冲器在同一撞击速度下阻力峰值不变（约 1.1 kN 量级），但轻量档能量减小、刹停深度变浅，脉宽相应缩短：

```
按 s = 3.5 mm：t = 2s/v = 2 × 3.5 / 3.12 = 2.2 ms
```

5.8mm 档参考主峰（按 1.75/2.6 缩放 §4 参考曲线的 875 N）为 589 N、3.5 ms 量级。

**结论**：需把阻尼档调低（换小一号 RB 系列，或按档位调整），把主脉冲落在 2.5 到 3.5 ms、峰值约 600 N 量级，与缩放后的参考主峰对齐；**台架实测为准（第一验收项）**。

### 12.6 齿轮链与电机重算

齿条副切向力 Ft₁ = 248 N，半齿轮轴转矩 T = Ft₁ × r = 248 × 9 = 2232 N·mm：

```
接触（与 √Ft 成正比）：σH = 715 × √(248/369) = 586 MPa < σHP = 775 MPa
                        SH实 = 775/586 = 1.32（原 1.08）✓
A-B 对（z24 档）：Ft₂ = 2T/d = 2 × 2232/24 = 186 N
                   σH = 758 × √(248/369) = 622 MPa，SH实 = 775/622 = 1.25（原 1.02 贴线）✓
                   z26 到 z30 档更富余
弯曲（与 Ft 成正比）：σF = 163 × 248/369 = 110 MPa < σFG = 640 MPa，SF实 = 5.8 ✓
```

**结论**：轻量档下齿轮链**全部档位余量充足**（连 z24 档都达 1.25），原"z24 贴线需复核"的不确定项可结案，选型按现货到货情况任选 z24 到 z30。

**传动链简化备选（2026-09-23 用户提出，"把半齿轮做到传动系另外的齿轮里面"）**：

若把半齿轮直接做在传动链已有齿轮上（例如取消 A-B 传动对与中间轴，让齿条直接与电机输出轴上的半齿轮啮合），链路由"电机 → A → B → 半齿轮 → 齿条"简化为"电机 → 半齿轮 → 齿条"：

- **收益**：省一对齿轮与一根中间轴；**第 6 章那根 Φ6/40Cr 中间轴（S 0.82 不合格）随构型消失**，第 6 章的强度问题自动结案；零件数与装配误差链同时缩短。
- **校核（按本备选构型）**：齿条推力 248 N、节圆半径 9 mm ⇒ 电机输出轴转矩 2.23 N·m（÷0.9 效率 2.48 N·m，为峰值 5.0 的 50%）✓；输出轴弯曲：齿条径向力 Ft·tanα = 248 × tan20° = 90 N，作用点到轴承按 15 mm 估，M = 90 × 15 = 1350 N·mm，Φ6 的 W = 21.2 mm³ ⇒ σb = 64 MPa，与扭剪 78 MPa 合成 σca = √(64² + (0.6×78)²) = 85 MPa ⇒ 合金钢输出轴 S > 3 ✓。
- **待核**：①电机输出轴需能装半齿轮（Φ6 轴、键/夹紧方式、轴向定位）；②齿条相对电机的位置与行程包络重排（启动 §8.8 的间隙校核）；③半齿轮的扇区角与释放窗不变（仍 140°/220°，每转一发）。
- **结论**：该简化对本书全部计算无实质影响，且消除第 6 章的失分项，**推荐采用**；采用后第 5.5 节 A-B 对与第 6.1 节中间轴作废。

### 12.7 轴系重算

载荷按 248/369 = 0.672 比例缩放（§6.1 修正后的横向合成载荷 300 到 570 N）：

```
横向合成载荷 => 202 到 383 N
弯扭合成：σca = 414 × 0.672 = 278 MPa => S = 340/278 = 1.22（40Cr，[σ-1] = 340 MPa）✓ 强度合格
挠度：f = 0.196 × 0.672 = 0.132 mm，仍大于许用 0.02 到 0.03 mm ✗
```

**结论**：强度合格（Φ6、40Cr 可保）；**刚度仍是控制条件**，需把轴承跨距由 60 mm 缩到 40 mm（f = 0.058 mm）或升 Φ8（f = 0.018 mm）。

### 12.8 组件实称与冲量标定（含摩擦修正）

```
按 §9.10 计入导轨与齿条摩擦：E摩擦 = 20 到 30 N × 21.99 mm = 0.44 到 0.66 J
I = √(2·(E − E摩擦)·m)
561 g、无摩擦：I = 1.75 N·s
561 g、含摩擦（取 0.55 J）：I = √(2 × 2.18 × 0.561) = 1.56 N·s => 损失约 11%
```

**结论**：摩擦损失 10 到 12% 必须计入标定式；其实测波动（温度、润滑、清洁度）是"逐发 ±5% 一致度"的主要风险，靠导轨精度与润滑管理压住，台架实测标定。

安装三条规则（按重要性排序）：

1. **反坐力线（枪线/齿条轴线）尽量穿过腕部两轴的交点**：腕部抗扰动的力矩 = 力 × 垂距，力臂越小越好；垂距 25 mm 时 248 N 的加速段反作用给腕部的力矩约 6.2 N·m，垂距降到 10 mm 约 2.5 N·m。

3. **法兰到模拟器用短而刚的转接件，中间夹 3 到 5 mm 弹性垫**：短件保证重心不外移；弹性垫吸收最高频那一小段冲击、保护减速器齿与轴承，并作为控制失效时的兜底（不与"关节浮动控制"方案冲突，两者可并用）。
