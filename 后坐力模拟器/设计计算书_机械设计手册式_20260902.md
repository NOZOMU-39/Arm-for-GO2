### §1 冲量-储能链：指标 → 粗算 → 选型 → 校核 → 修正 → 定案

**1.1 粗略计算（初选 800 g 档）**
- 冲量约束 I = m·v：v = 2.6 / 0.80 = 3.25 m/s；动能 E = 0.5·m·v² = I²/(2m) = 4.23 J
- 击发弹簧储能需求 E = 0.5·k·S² → 初选行程 S = 22.4 mm（TF27，k = 16.77 N/mm）

**1.2 齿轮整齿离散修正（本方案的关键约束）**
- 不完全齿轮驱动时齿条行程只能取"完整齿数 × 齿距"：S = n·π·m，齿缺边界落在齿谷
- 把链条倒排：S → E = 0.5·k·S² → m = I²/(2E)，在组件 0.75 到 1.0 kg 窗口内枚举标准模数（m 等于 1.0、1.25、1.5）：
  - m1.0 × 7 齿：S = 21.99 mm，E = 4.05 J → m = 834 g ✓ 窗口内唯一解
  - m1.0 × 6 齿（18.85 mm）→ 1135 g；m1.0 × 8 齿（25.13 mm）→ 638 g（缓冲贴 90%）；m1.25、m1.5 无整数解或出窗
- **定案：行程 21.99 mm（7 完整齿 × m1.0）、每发储能 4.05 J、组件 834 g、撞击速度 3.12 m/s**

**1.3 击发弹簧（TF27，自由长 70，k = 16.77）校核**
- 满压缩 S = 21.99 mm，为额定压缩 28 mm 的 78.5%；压缩率 31.4%（寿命线 40% 内，10 的 6 次方 次规格成立）
- 峰值力 F = k·S = 369 N，为额定 470.7 N 的 78.4%；压缩后长度 48.0 mm，大于密着高 31.5 mm ✓
- 储能 = 0.5 × 16.77 × 21.99² = 4054 N·mm = 4.05 J ✓
- 装配指标：允许从自由长零力起压缩（标准工况）；静止微预压 0 到 0.5 mm（静力 0 到 8 N，仅消除装填空程）；释放点 = 满压缩 21.99 mm 处几何确定

**1.4 修正记录**：800 g/22.4 mm 初选 → 齿轮整齿约束修正 → 834 g/21.99 mm 定案（冲量 2.6 不变，组件实称 ±50 g 只动冲量标定值约 ±1.5%）

**2.1 缓冲器（SMC RB1007，M10×1.0，行程 7 mm，最大吸收能量 5.88 J，当量质量 0.07 到 1.5 kg，速度 0.05 到 5 m/s；尺寸：LL 53.7 / 本体 46.7 / 杆径 3 / 全伸露出 7 = 行程）**

**2.2 刹停核算（弹力弹簧并联 k = 44.9、预压 1 mm；能量法，阻尼平均阻力档）**

### §3 装填齿轮链设计计算（GB/T 3480-2019 承载能力体系）

**3.1 传动方案与载荷工况**
- 链：2325 输出 → 锥齿轮 1:1（90 度换向）→ 齿条副轴 → 半齿轮-齿条 → 活块装填 21.99 mm
- 工况：每发一次推程压缩击发弹簧，齿条推力 0 到 369 N 线性增长（末端峰值）；推程约 100 ms（4 Hz）到任意慢（单发）；寿命 10 的 6 次方 次；节圆线速度 v = 0.23 m/s（低速重载脉冲工况）

**3.2 粗略计算**
- 齿条副轴扭矩 T = F·r = 369 × 9 = 3.32 N·m；锥齿轮 1:1 传递同值
- 半齿轮每圈一发、转速 = 射速（4 Hz = 240 rpm），与节圆无关

**3.3 初选（未经系数校核）**
- 半齿轮 m1.0 z18（节圆 Φ18，扇区 7 齿 140 度，齿缺 220 度）、齿条同模数、齿宽 8
- 锥齿轮 m1.5 z25（Φ37.5）、齿宽 8

**3.4 校核（接触与弯曲强度，含工况修正系数）**
系数选取（按 GB/T 3480 / ISO 6336，机械设计手册取值）：
- KA 使用系数 = 1.1（伺服位置模式可控斜坡驱动、装填力从零线性爬升、仅逐齿进啮微冲击——平稳驱动偏轻微冲击档；2026-09-10 用户确认单向旋转无反向载荷）
- Kv 动载系数 = 1.05（节圆线速 0.23 m/s，8 级精度低速区）
- KHβ/KFβ 齿向载荷分布 = 1.10（窄齿、无齿向修形）
- KHα/KFα 齿间载荷分配 = 1.10（重合度低、8 级）
- 寿命系数 ZN = 1.55、YNT = 1.6（循环次数 2 乘 10 的 4 次方，调质钢档，2026-09-10 用户定寿命）
- 材料许用（σHlim·ZN/SH）：45#/S45C 调质 σHP = 550 × 1.55/1.1 = 775 MPa；40Cr 调质 σHP = 700 × 1.55/1.1 = 986 MPa（奥氏体不锈钢接触许用约 350 级，出局）
- 几何：ZE = 189.8（钢-钢）、ZH = 2.5（20 度无变位）、Zε = 0.89（直齿 εα ≈ 1.6）

接触应力（半齿轮-齿条，凸齿对平面，(u+1)/u → 1）：
σH = ZE·ZH·Zε·根号(KA·Kv·KHβ·KHα·Ft/(b·d1)) = 474.5·根号(1.33·Ft/(b·d1))

**3.5 校核结果与修正计算（留痕）**
| 轮次 | 方案 | 结果 | 修正动作 |

**3.6 定案参数与最终校核**
半齿轮-齿条（S45C 调质，许用 775）：
- 半齿轮 m1.0、z18、扇区 7 齿 140 度、齿缺 220 度、齿宽 15 mm
- 齿条 m1.0、齿宽 15、长约 31 mm（10 齿）
- 接触 σH = 474.5·根号(1.33 × 369/(15 × 18)) = 699 MPa ≤ 775，S = 1.11 ✓
- 弯曲 σF ≈ 100 MPa（单向脉动，YNT 1.6 后许用更高），S 大于 3 ✓（弯曲不控制）
锥齿轮副（40Cr 调质或现货等强度件，1:1，45 度分锥，单向旋转）：
- **m1、z25 对 z25、Φ25、齿宽 6**（锥距 17.7，R/3 = 5.9，取 6 超 2% 工程接受）；锥小齿 Φ6 孔直装 2325 输出轴，锥大齿 Φ8 孔装齿条副轴

- 弯曲约 90 MPa（单向脉动），富余 ✓
- 轴向力 Fa = Ft·tan(20 度)·sin(45 度) ≈ 82 N（由外部轴承承接，不进 2325 内部）

**3.7 轴系校核（弯扭合成）**
- 锥小齿直装 2325 输出轴（Φ6，电机厂件），轴端扭矩 3.32 N·m 对应 τ ≈ 78 MPa，由减速输出轴厂标保证；锥齿轴向力 82 N 由电机输出端外部轴承座承接（布置要求：轴向力顶到 2325 内部轴承之前先被外部轴肩/轴承吃掉）
- 齿条副轴（锥大齿 + 半齿轮同轴）取 Φ8、40Cr 调质：扭转 τ = 16 × 3321/(π × 512) = 33 MPa；叠加锥齿径向/轴向力（82 N 级）弯曲后弯扭合成当量应力约 60 MPa，静强度安全系数大于 3 ✓

**3.8 电机驱动校核（DM-S2325-1EC）**
- 装填峰值扭矩 = 369 × 9 = 3.32 N·m（弹簧纯力）；含两级齿轮效率约 0.9 → 2325 端 3.69 N·m = 峰值 5.0 的 74% ✓
- 推程内平均 1.66 N·m（超额定 1.35 的瞬时段，单次推程约 100 ms、低占空比）
- 循环平均（啮合占空约 39% + 摩擦）约 0.8 N·m，额定 1.35 内 ✓

## 2. 活块设计（冲量等效）

### 原理
`I = m·v；E = I²/2m`（动量定理+动能定理）——**m 越大储能越小**，但质量受体积/材料约束。

### 选型与校核
- 全钢 45#/40Cr，**48×31×38mm**，m = 56.5cm³×7.85 = **444g**（不用钨：加宽换质量路线已判否，碟簧解决缓冲后无需降速）
- v = 2.5/0.444 = **5.6 m/s**；E = **7.0 J** ✓
- 飞行段摩擦 <1N（齿条脱开、无偏心载荷），冲量损失 <1% ✓

### 修正记录
v3.4 曾用 750g 重活块降速（治缓冲应变），碟簧方案落地后收回——轻活块+20mm 行程为最终形态。

## 3. 弹簧设计（能量存储，v3.5＝现货模具弹簧 FL75）

### 原理
- 储能：E = ½k(x_fc² − x₀²)（力-位移梯形面积，预压段不计入）
- 圆线弹簧刚度 k = Gd⁴/8D³n（扭转圆棒模型）；**模具弹簧按"外径×长度×载荷等级"查表**（等载荷分级：同一外径最大载荷标准化，k 随自由长变化）

### 选型（2026-09-04 用户人工确认商家表）
```
模具弹簧 轻负荷·100万次级：OD30 × ID16 × FL75
k = 18.93 N/mm｜密着高 33.8mm｜100万次额定：压缩 30mm（40%）/ 载荷 568.8N
```
候选对比：FL70（k=20.10）压缩率需 39.4% 贴 40% 极限 → 判否；**FL75 首选**（k 落 18~21 窗口、压缩率 37.8%）；FL80（17.65/36.6%，整机 160mm）、FL90（15.69/34.4%，170mm）备选。

### 工作点校核（预压 x₀=8mm）
```
x_fc = √(2×7000/18.93 + 8²) = 28.35mm → F_fc = 537N（≤568.8 额定 ✓，=DM 峰值 96.6%）
行程 20.35mm｜压缩率 37.8%（≤40% 额定，寿命 ≥100万次）｜静置 67mm
储能 = ½×18.93×(28.35²−8²) = 7.0J ✓
冲量-预压表：x₀=2/4/8/9.6mm → I = 2.0/2.2/2.5/2.6 N·s（x₀≤9.6 保 x_fc≤30 额定）
```

### 修正记录
- v3.3 圆线 d4.5×95 定制（k 精确但需等货）→ v3.5 现货模具弹簧 FL75（等载荷现货、寿命分级、弹簧区 87→67mm、整机 180→155mm）——现货化红利兑现。

## 4. 缓冲设计（v3.5＝碟簧组 + 阻尼面层）

### 原理（大白话）
- 活块撞缓冲，缓冲要把它在 ~5ms 里停下来，还要把峰值力控制在 1kN 以内；
- 理想情况是"缓冲推活块的力从头到尾差不多大"（恒力），这样同样的刹车距离里峰值最小；
- 实心聚氨酯不行：它近于不可压缩，压 65% 时体积几乎不变、会往侧面鼓 2.9 倍，封闭通道里鼓不开 → 力会暴涨；而且它越压越硬，真实峰值是直线估算的 1.5~2 倍 → 判否；
- 泡沫回弹慢（粘弹性材料，5Hz 连发时第二发会撞在没回弹完的垫子上）→ 判否；
- 碟簧（GB/T 1972 现货）是钢的：回弹瞬时完成、力-压入曲线有平台段（接近"恒力"，峰值最小）、不蠕变不老化的材料问题 → 选用。

### 结构与静止基准（v3.6 新增，用户设计）
```
后盖 → 碟簧组（导向杆上）→ 压板 → 阻尼面层 3mm → 活块
锁紧套筒：把碟簧组预压锁定在 200N（顶住压板，碟簧不能松回去）
静止时：活块被主弹簧推着压在压板上，力走"压板→套筒→后盖"硬路，
        碟簧不变形 → 静止位 = 套筒位置 = 固定几何基准（与主弹簧预压无关）
击发时：活块把压板往后压，碟簧从 200N 起步变形到峰值（≤900N），行程 ~13mm
锁 200N 的理由：主弹簧预压上限 182N，碟簧锁力 ≥182N 时静止位永不漂 → 锁 200N（+10% 裕量）
```

### 选型与校核
```
需求锚点：预载 200N；动态压入 ~13mm 内峰值 ≤900N（框架预算 1kN）
单片窗口：外径 Φ28~40（GB/T 1972 系列）；F@0.75h₀ ∈ 600~1000N；h₀ ∈ 0.8~1.2mm
串联片数 n ≈ 动态行程/(0.75h₀) → 12~16 片；叠合高 n×t ≤ ~22mm
能量：7.6J（7.0 主簧动能 + 0.6 预压残余）从 200N 点起吸收 → 脉宽 ~5ms（数值积分定稿）
阻尼面层 3mm：Sorbothane/阻尼硅胶（要高阻尼，不是 85A 那种硬——硬≠阻尼）
碟簧 e≈0.8：第一击瞬时冲量 (1+e)·mv，总冲量守恒，幅度实测定稿
```

### 修正记录
v3.3 实心 30A（65% 应变+封闭桶）→ 判否 → 碟簧方案 → v3.6 加锁紧套筒：预载锚点 151→**200N**，静止位从"力的平衡点"改为"几何限位"，主弹簧调档不再影响静止位，调校简化为单旋钮（主簧预压）。

## 5. 半齿轮-齿条设计（运动转换）

### 原理
`S = r·θ`（节圆纯滚动）；齿根弯曲 Lewis σ_b = F/(b·m·Y)；接触 Hertz σ_H = Z_E√(F/bd)。

### 选型（行程 20.35mm、啮合角 ~130°）
```
r = S/θ：θ=130°=2.269rad → r = 8.97mm → 节圆 Φ18（m1.5，全轮 12 齿）
扇区 5 齿（覆盖 150° > 130° ✓）；齿宽 10mm；45# 调质
```

### 校核
- 齿根弯曲：σ_b = 537/(10×1.5×0.26) = **138 MPa** < 250（SF 1.8）✓
- 齿面接触：σ_H = 189.8×√(537/180) = **328 MPa** < 600 ✓
- 首齿导入倒角降啮合冲击 ✓

### 5.4 伞齿对与齿轮轴（v3.3 几何勘误后沿用）
```
两级伞齿转向（单级伞齿需轴线相交，电机轴与跨宽轴异面高差不可行）：
伞齿①/② 各 1:1，Φ26，m1.25，z=20/20，齿宽 8mm → σ_b ≈ 137 MPa ✓
竖短轴 Φ8：τ ≈ 50 MPa ✓；跨宽轴 Φ8：τ ≈ 50 MPa ✓（两端轴承）
```

## 附：公式原理索引

| 公式 | 原理 |
|---|---|
| I = ∫F·dt | 动量定理 |
| E = ½mv² = I²/2m | 动能定理 |
| E = ½k(x²−x₀²) | 力-位移梯形面积 |
| t = 2d/v、F=2E/d | 匀减速/恒力模型（上限估计） |
| F_peak = (n+1)E/d | 硬化元件 F=Cxⁿ 的真实峰值 |
| S = r·θ | 齿轮啮合基本定律 |
| σ_b = F/(b·m·Y) | Lewis 悬臂梁模型 |
| σ_H = Z_E√(F/bd) | Hertz 接触 |
| P = T·ω = F·v | 功率定义 |
| Δω = I·d/J | 角动量定理 |
