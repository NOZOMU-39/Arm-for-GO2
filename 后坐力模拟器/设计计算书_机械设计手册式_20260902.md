## 2. 活块设计（冲量等效）

### 原理
`I = m·v；E = I²/2m`（动量定理+动能定理）——**m 越大储能越小**，但质量受体积/材料约束。

### 选型与校核
- 全钢 45#/40Cr，**48×31×38mm**，m = 56.5cm³×7.85 = **444g**（不用钨：加宽换质量路线已判否，碟簧解决缓冲后无需降速）
- v = 2.5/0.444 = **5.6 m/s**；E = **7.0 J** ✓
- 飞行段摩擦 <1N（齿条脱开、无偏心载荷），冲量损失 <1% ✓

### 修正记录
v3.4 曾用 750g 重活块降速（治缓冲应变），碟簧方案落地后收回——轻活块+20mm 行程为最终形态。

## 3. 弹簧设计（能量存储，v3.5＝现货模具弹簧 FL75）

### 原理
- 储能：E = ½k(x_fc² − x₀²)（力-位移梯形面积，预压段不计入）
- 圆线弹簧刚度 k = Gd⁴/8D³n（扭转圆棒模型）；**模具弹簧按"外径×长度×载荷等级"查表**（等载荷分级：同一外径最大载荷标准化，k 随自由长变化）

### 选型（2026-09-04 用户人工确认商家表）
```
模具弹簧 轻负荷·100万次级：OD30 × ID16 × FL75
k = 18.93 N/mm｜密着高 33.8mm｜100万次额定：压缩 30mm（40%）/ 载荷 568.8N
```
候选对比：FL70（k=20.10）压缩率需 39.4% 贴 40% 极限 → 判否；**FL75 首选**（k 落 18~21 窗口、压缩率 37.8%）；FL80（17.65/36.6%，整机 160mm）、FL90（15.69/34.4%，170mm）备选。

### 工作点校核（预压 x₀=8mm）
```
x_fc = √(2×7000/18.93 + 8²) = 28.35mm → F_fc = 537N（≤568.8 额定 ✓，=DM 峰值 96.6%）
行程 20.35mm｜压缩率 37.8%（≤40% 额定，寿命 ≥100万次）｜静置 67mm
储能 = ½×18.93×(28.35²−8²) = 7.0J ✓
冲量-预压表：x₀=2/4/8/9.6mm → I = 2.0/2.2/2.5/2.6 N·s（x₀≤9.6 保 x_fc≤30 额定）
```

### 修正记录
- v3.3 圆线 d4.5×95 定制（k 精确但需等货）→ v3.5 现货模具弹簧 FL75（等载荷现货、寿命分级、弹簧区 87→67mm、整机 180→155mm）——现货化红利兑现。

## 4. 缓冲设计（v3.5＝碟簧组 + 阻尼面层）

### 原理（大白话）
- 活块撞缓冲，缓冲要把它在 ~5ms 里停下来，还要把峰值力控制在 1kN 以内；
- 理想情况是"缓冲推活块的力从头到尾差不多大"（恒力），这样同样的刹车距离里峰值最小；
- 实心聚氨酯不行：它近于不可压缩，压 65% 时体积几乎不变、会往侧面鼓 2.9 倍，封闭通道里鼓不开 → 力会暴涨；而且它越压越硬，真实峰值是直线估算的 1.5~2 倍 → 判否；
- 泡沫回弹慢（粘弹性材料，5Hz 连发时第二发会撞在没回弹完的垫子上）→ 判否；
- 碟簧（GB/T 1972 现货）是钢的：回弹瞬时完成、力-压入曲线有平台段（接近"恒力"，峰值最小）、不蠕变不老化的材料问题 → 选用。

### 结构与静止基准（v3.6 新增，用户设计）
```
后盖 → 碟簧组（导向杆上）→ 压板 → 阻尼面层 3mm → 活块
锁紧套筒：把碟簧组预压锁定在 200N（顶住压板，碟簧不能松回去）
静止时：活块被主弹簧推着压在压板上，力走"压板→套筒→后盖"硬路，
        碟簧不变形 → 静止位 = 套筒位置 = 固定几何基准（与主弹簧预压无关）
击发时：活块把压板往后压，碟簧从 200N 起步变形到峰值（≤900N），行程 ~13mm
锁 200N 的理由：主弹簧预压上限 182N，碟簧锁力 ≥182N 时静止位永不漂 → 锁 200N（+10% 裕量）
```

### 选型与校核
```
需求锚点：预载 200N；动态压入 ~13mm 内峰值 ≤900N（框架预算 1kN）
单片窗口：外径 Φ28~40（GB/T 1972 系列）；F@0.75h₀ ∈ 600~1000N；h₀ ∈ 0.8~1.2mm
串联片数 n ≈ 动态行程/(0.75h₀) → 12~16 片；叠合高 n×t ≤ ~22mm
能量：7.6J（7.0 主簧动能 + 0.6 预压残余）从 200N 点起吸收 → 脉宽 ~5ms（数值积分定稿）
阻尼面层 3mm：Sorbothane/阻尼硅胶（要高阻尼，不是 85A 那种硬——硬≠阻尼）
碟簧 e≈0.8：第一击瞬时冲量 (1+e)·mv，总冲量守恒，幅度实测定稿
```

### 修正记录
v3.3 实心 30A（65% 应变+封闭桶）→ 判否 → 碟簧方案 → v3.6 加锁紧套筒：预载锚点 151→**200N**，静止位从"力的平衡点"改为"几何限位"，主弹簧调档不再影响静止位，调校简化为单旋钮（主簧预压）。

## 5. 半齿轮-齿条设计（运动转换）

### 原理
`S = r·θ`（节圆纯滚动）；齿根弯曲 Lewis σ_b = F/(b·m·Y)；接触 Hertz σ_H = Z_E√(F/bd)。

### 选型（行程 20.35mm、啮合角 ~130°）
```
r = S/θ：θ=130°=2.269rad → r = 8.97mm → 节圆 Φ18（m1.5，全轮 12 齿）
扇区 5 齿（覆盖 150° > 130° ✓）；齿宽 10mm；45# 调质
```

### 校核
- 齿根弯曲：σ_b = 537/(10×1.5×0.26) = **138 MPa** < 250（SF 1.8）✓
- 齿面接触：σ_H = 189.8×√(537/180) = **328 MPa** < 600 ✓
- 首齿导入倒角降啮合冲击 ✓

### 5.4 伞齿对与齿轮轴（v3.3 几何勘误后沿用）
```
两级伞齿转向（单级伞齿需轴线相交，电机轴与跨宽轴异面高差不可行）：
伞齿①/② 各 1:1，Φ26，m1.25，z=20/20，齿宽 8mm → σ_b ≈ 137 MPa ✓
竖短轴 Φ8：τ ≈ 50 MPa ✓；跨宽轴 Φ8：τ ≈ 50 MPa ✓（两端轴承）
```

## 7. 框架与导向（强度与偏心）

- 尾板（6061 10mm）：σ = M/Z ≈ 25 MPa < 240（SF ~9）✓；M5×4 剪切 ≈ 13 MPa ✓
- 偏心（齿条啮合力 537N@偏距 18mm）：倾覆 ~13 N·m → 导向条反力 ~350N/条 → PTFE 承压 ~0.9 MPa ✓；摩擦 ~60~140N（仅上簧段，电机多耗 ~2J/圈，DM 预算内）
- 弹簧屈曲：模具弹簧短粗（FL75/OD30，λ≈2.5 两端导向）无屈曲问题 ✓
- 预紧耦合（2026-09-04 确认）：静置时弹簧 151N ↔ 碟簧预压 151N 经活块自平衡，前后端板被 151N 撑开由侧板内部张力承担，对外零合力；碟簧组导向杆需预压调节螺母，预压力=弹簧预压力
