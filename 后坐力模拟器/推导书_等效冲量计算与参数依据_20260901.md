**装配条件与指标（实现由用户自定）**：

- 机架后墙固定受力板；RB1007 本体与两根弹力弹簧都装在运动组件上、杆尖与弹簧端朝后顶受力板，三者并联。轴线平行于运动方向。
- RB1007：杆全伸、杆尖与受力板留 0 到 1 毫米间隙；任何静止状态下杆不得受压（禁预压杆）；杆径仅 3 毫米，安装须对中，偏载会弯杆；杆全伸露出 7 毫米等于行程，压到底杆端与本体端面齐平，齐平后再撞是金属硬碰；能量须在 7 毫米行程内吃完，组件停稳前缓冲器不得到底（刹停余量 1.0 到 2.9 毫米即此验收依据）。
- 弹力弹簧（缓冲侧）：两根并联，各预压 0.5 到 1 毫米，合计静力 22 到 45 牛，兼三职（静止定位、缓冲起点确定、撞击刹停兜底与回位）。
- 击发弹簧（储能侧）：允许从自由长零力起压缩（标准工况，规格额定即按自由长计）；静止态微预压 0 到 0.5 毫米（刚抵住无间隙即可，静力 0 到 8 牛），预压只消除装填空程，不承担定位；每发释放点 = 满压缩 21.99 毫米处（几何确定，由装填行程保证）。
- 静止力平衡条件：组件静止时受两侧弹簧合计静力约 22 到 53 牛（缓冲侧为主），须由结构的静止基准（齿条啮合位或限位，用户自定）承受；组件静止位漂移不大于正负 0.2 毫米（逐发一致性正负 5% 目标的分配量）。
- 解耦条件：两侧弹簧的静力不得经组件互相耦合，即任何静止状态下，缓冲弹簧有效预压变化不大于正负 0.2 毫米、击发弹簧被动压缩不大于 0.5 毫米、RB1007 杆间隙保持 0 到 1 毫米。装配时按此三指标验收。
- 击发弹簧端（弹射侧）回弹敲击与装填进齿冲击由齿形倒角与端部垫片处理，指标为：不对冲量与逐发一致性造成可测影响。
- 装填链空间指标（2026-09-10）：齿条随活块往复运动（行程 21.99 毫米）的扫掠区，与 DM-S2325-1EC 外廓（约 28 乘 78 毫米，含线缆余量）之间最小间隙不小于 3 毫米——电机居中布置时优先让电机轴向错开齿条行程带；验收按间隙指标查。
- 锥齿轴向力（约 82 牛）由 2325 输出端外部轴承座承接，不得作用在 2325 内部轴承上。

**已知不确定项**：一，缓冲器峰值力特性：RB1007 手册无最大阻力字段，峰值与低速段特性只能台架实测（原 AC1412-2 有效重量错配八倍问题已于 2026-09-08 结案）；二，真枪参考力曲线形状依赖测试装置刚度，双峰第二峰单缓冲只做近似；三，弹药参数与真枪冲量基准不确定度正负百分之十五，待真枪实测校准；四，回弹速度与二次冲击实测定稿；五，缓冲器持续使用频率上限 70 次每分，短爆秒级 1 到 4 赫兹不受限；六，组件实称在 0.75 到 1.0 千克内直接代入零换件（冲量随实称标定），超出才需重算；七，24 伏高扭矩掉速：4 赫兹连发贴线，48 伏升压或限 3 赫兹；八，齿轮校核载荷按弹簧峰值 369 牛静态取用并叠加 KA 1.1（可控斜坡、单向）与 Kv/KH 系数，锥齿安全系数 1.01 贴线——台架实测 2325 电流可反推实际齿载复核；若实测冲击超预期（进齿噪声大、齿面早期点蚀），后备为寿命降至 1 万发（S 升 1.05）或齿宽加到 6.5 到 7。

## 0. 结论摘要

- **等效原理**：活块动量 = 真枪后坐冲量（动量守恒），脉宽由缓冲单独调。
- **设计点 2.5 N·s**（预压可调 2.0~2.6）：全钢活块 48×31×38 ≈444g；**模具弹簧 OD30×ID16×FL75（k=18.93）**；碟簧组缓冲。
- **整机 155×56×72mm、~1.4kg**；驱动达妙 DM-2325（输出→半齿轮 1:1），峰值负载 96.6%。
- 决策链：目标 92式 9mm/5.8mm（4/2.9 N·s）→ 关节硬件 + 用户约束（材料常用/现货/不用钨/≤180×80）→ v3.5 定稿 2.5 N·s。

## 1. 等效目标：参考数据

### 1.1 冲量定义
后坐本质量是**冲量**：`I = ∫F·dt = Δp`。真枪总后坐冲量近似 `I ≈ m_b·v_b + m_g·v_g,eff`（弹头动量 + 燃气附加动量，手枪按弹头动量的 25~40% 估）。

### 1.2 目标武器参考（公开资料典型值，±10~30% 不确定度）
| 弹种 | 弹头 | 初速 | 弹头动量 | 燃气附加 | 总冲量 I |
|---|---|---|---|---|---|
| 92式 9mm | 8g | 350~380 | 2.8~3.0 | ~0.9~1.1 | ≈3.8~4.0 N·s |
| 92式 5.8mm | 4.8g | 460~480 | 2.2~2.3 | ~0.6 | ≈2.8~2.9 N·s |
| 54式 | 5.5g | 420~440 | 2.3~2.4 | ~0.8 | ≈3.1~3.3 N·s |
| 64式 | 4.8g | ~300 | 1.4 | ~0.3 | ≈1.7 N·s |

### 1.3 为什么用冲量
控制对象是平台动量扰动（守恒量，与过程无关）；力峰值由脉宽决定，是二阶特性。真枪主脉冲 5~8ms 为脉宽对标。

## 2. 等效计算：目标冲量 → 模拟器参数

### 2.1 冲量等效：活块动量
```
I = m·v = 2.5 N·s；E = ½mv² = I²/2m = 7.0 J（m=444g）
```
- 活块：全钢 45#/40Cr，48×31×38mm ≈444g（用户定：不用钨、20mm 级行程、低刚度）
- v = 5.6 m/s（击发飞行段摩擦 <1N，冲量损失 <1%）

### 2.2 能量等效：弹簧（v3.5 定稿＝现货模具弹簧 FL75）
**储能公式**：`E = ½k(x_fc² − x₀²)`（力-位移梯形面积）。

**选型（用户人工确认商家表行，2026-09-04）**：
```
模具弹簧 轻负荷·100万次级：OD30 × ID16 × FL75
k = 18.93 N/mm｜密着高 33.8mm｜额定（100万次）压缩 30mm/载荷 568.8N
```

**工作点计算**：
```
x_fc = √(2E/k + x₀²) = √(14000/18.93 + 8²) = 28.35mm（预压 x₀=8mm，F₀=151N）
F_fc = k·x_fc = 537N（≤ 额定 568.8N ✓；= DM 峰值 5.0N·m 的 96.6%）
行程 s = 28.35 − 8 = 20.35mm；压缩率 28.35/75 = 37.8%（≤ 40% 额定 ✓）
储能 E = ½×18.93×(28.35²−8²) = 7.0J ✓
静置长度 = 75 − 8 = 67mm
```

**冲量-预压标定表**（行程固定 20.35mm；k 实测偏离时以实测重标）：
```
E(x₀) = ½k((x₀+s)² − x₀²)；I = √(2E·m)；x₀ 上限 9.6mm（x_fc≤30 额定）
```
| 预压 x₀ | 预压力 | 冲量 I | 备注 |
|---|---|---|---|
| 2mm | 38N | ~2.0 N·s | |
| 4mm | 76N | ~2.2 N·s | |
| **8mm（设计点）** | **151N** | **2.5 N·s** | 压缩率 37.8% |
| 9.6mm | 182N | ~2.6 N·s | x_fc=30mm=额定上限 |

**候选对比（同系列其余自由长）**：FL70（k=20.10）需压 39.4% 贴 40% 极限——疲劳余量不足，判否；FL80（k=17.65，压缩率 36.6%，整机 160mm）、FL90（k=15.69，34.4%，170mm）可用但设备更长。**FL75 为最优折中**。

### 2.3 时间等效：缓冲（碟簧组 + 锁紧套筒，v3.6，大白话版）

**先说这套东西怎么工作，再说为什么这么设计：**

结构（从后往前）：后盖 → 碟簧组（穿在导向杆上）→ 压板 → 3mm 阻尼面层 → 活块。导向杆尾部有一个**锁紧套筒**。

**静止时**：碟簧组被套筒预压锁定在 200N（碟簧压住后，套筒顶住压板，不让碟簧松回去）。活块被主弹簧往后推（38~182N，看你调的档位），压在阻尼面层/压板上——但压板被套筒硬顶着，**活块的力走"压板→套筒→后盖"这条硬路，碟簧本身不变形**。所以活块的静止位 = 套筒定住的位置，是个**固定的几何基准**，主弹簧预压怎么调都不影响它（这就解决了"调档位→静止位漂移→齿轮对不上齿"的老问题）。

**击发时**：活块以 5.6m/s 撞回来，把压板往后压——压板离开套筒，开始压碟簧。碟簧的力**从 200N 起步**往上走（不是从 0 开始），压到峰值（≤900N）时活块停下，然后碟簧把它弹回去。能量账：活块带 ~7.6J 撞进来（7.0J 是主弹簧给的动能，0.6J 是它往回飞时主弹簧还推了它一段），全部由碟簧吸收，脉宽 ~5ms。

**为什么锁 200N 而不是别的数**：主弹簧预压最大能调到 182N。碟簧锁的力只要 ≥182N，静止时活块就永远推不动压板——静止位就永远不动。锁 200N = 182N + 10% 余量。

**好处总结**：①调冲量档位只拧主弹簧一个旋钮，不用再补偿任何东西（齿条微调只在装配时对一次）；②碟簧力从 200N 起步，脉冲起跳更陡，更像真枪；③碟簧是钢的、回弹瞬时完成，5Hz 连发每一发都一样。

**老账也记着（为什么不用别的缓冲）**：实心 30A 聚氨酯不行——它近于不可压缩，压 65% 时体积几乎不变、往侧面鼓 2.9 倍，封闭通道里鼓不开，力会暴涨；而且越压越硬，真实峰值是直线估算的 1.5~2 倍。泡沫回弹慢（粘弹性，5Hz 连发第二发会撞在没回弹完的垫子上）。

**阻尼面层 3mm**（Sorbothane/阻尼硅胶，要"阻尼好"不是"硬"——硬≠阻尼）：把活块回弹速度吃掉一部分、给撞击后的振荡提供阻尼，让活块尽快停稳。碟簧自己回弹太利索（回弹系数 e≈0.8），第一击会多给机架 (1+e) 倍的瞬时冲量——总冲量守恒不变，但幅度要实测确认。

**选型需求（拿到商家参数后校核）**：预载锚点 **200N**；动态压入 ~13mm 内峰值 ≤900N；单片在压到 75% 行程时的力 600~1000N；单片极限行程 h₀ 0.8~1.2mm（决定串联片数）；叠合总高 ≤~22mm（不含面层和端板）。实测力-压入曲线后做数值积分定稿。

### 2.4 连发机构：半齿轮 + 齿条（每圈一发）
```
啮合段（~130°）：齿条啮合，活块前推 20.35mm 压缩弹簧
齿缺段（~230°）：齿条脱开，活块弹回撞碟簧（~5ms），齿轮继续转，无归位死区
半齿轮：节圆 Φ18，m1.5，全轮 12 齿，扇区 5 齿（130°≤5 齿覆盖 150° ✓），齿宽 10mm，45# 调质
齿根弯曲 σ = 537/(10×1.5×0.26) ≈ 138 MPa ✓
```

## 5. 不确定度与校准计划

- 冲量不确定度：弹药参数 ±10~30% → 总 ~±15%；弹簧 k 以实测为准（预压标定吸收）；DM 规格以实物为准。
- 校准路径：①真枪测力台实测（最理想）；②公开实测文献；③模拟器自身压电测力板标定"预压↔冲量"曲线（出厂必做，±10% 内）。
- **缓冲定稿流程（v3.5 起）**：买碟簧组 + 阻尼面层样品 → 压测 F(x) → 数值积分出 F(t)（峰值/脉宽/回弹 e）→ 校核框架 1kN 预算与腕关节 → 定稿。
- 待实测：臂各段重量/重心、X8-PRO 实物减速比、碟簧实际平台力、弹簧实际 k。

## 附：单位与公式速查

- 冲量：1 N·s = 1 kg·m/s；I = ∫F·dt
- 动能：E = ½mv² = I²/2m
- 弹簧：E = ½k(x²−x₀²)；k = G·d⁴/(8·D³·n)（圆线）；模具弹簧查表
- 硬化缓冲峰值：F_peak = (n+1)E/d（F=Cxⁿ）；恒力理想：F = E/d
- 半齿轮：节圆半径 r = 行程/啮合弧角(rad)
- 角冲量：Δω = I·d/J
