## 第 1 章 设计任务书

### 1.1 设计目的

设计一台安装于机械臂末端的后坐力模拟器，以机电方式产生半自动手枪级的**力-时间历程**，为无人平台武器臂的后坐扰动抑制与动态射击工作空间研究提供可重复、可标定、无实弹的扰动激励源。

与实弹射击相比，本装置解决三个问题：一是无需靶场与弹药即可反复实验；二是每发的力-时间历程可测量、可标定，扰动输入因而是已知量而非未知量；三是射速、连发节奏、安装姿态均可控，便于对照实验。

### 1.2 设计需求（原始数据）

**（1）对标对象与扰动量级**

对标 5.8×21mm 手枪弹（92 式 5.8mm 手枪用）。单发冲量由弹头动量与燃气动量两部分构成：

```
弹头质量 m_b = 3.0 g，初速 v_0 = 480 m/s       => 弹头动量 m_b·v_0 = 1.44 N·s
发射药质量 m_p ≈ 0.35 g（全弹 6.0 g 扣除弹头与弹壳），燃气速度系数 β ≈ 1.5
单发冲量 I = m_b·v_0·(1 + β·m_p/m_b) = 1.44 + 0.25 = 1.69 N·s      ……(1-1)
```

燃气项受装药量与燃气速度系数不确定度影响，按偏保守取 **设计冲量 I = 1.75 N·s**（该弹的物理上限为 3.0×480 + 0.5×1.75×480 = 1.86 N·s）。

**（2）其他原始数据**

| 序号 | 项目 | 数值 | 说明 |
|---|---|---|---|
| 1 | 单发冲量 I | 1.75 N·s | 式(1-1)及上文的偏保守取值 |
| 2 | 冲量一致度 | 逐发 ±5%（标定后） | 研究数据质量要求 |
| 3 | 射速 | 单发为主；速射 1 到 4 Hz | 半自动手枪实际速射节奏 |
| 4 | 设计寿命 | 2 万发 | 课题周期内实验量量级 |
| 5 | 供电 | 24 V 直流母线 | 平台统一供电（驱动器支持至 48 V） |
| 6 | 安装位置 | 机械臂末端法兰 | 经末端云台与腕部相连 |

### 1.3 边界条件与约束

- **承载关节**：末端腕关节 X2-P28-7，额定转矩 2.5 N·m、峰值 7 N·m；本机自重与射击动态载荷均经该关节传递；
- **平台负载预算**：四足平台额定负载 8 kg，已含机械臂约 3.8 kg、视觉与 IMU 传感器约 0.3 kg，本机质量目标 ≤ 1.5 kg；
- **结构包络**：受臂末端与平台干涉限制，整机长度控制在 130 mm 级；本机重心到腕轴的距离暂按 80 mm 计（后续结构优化若可减小，腕部静载相应下降）；
- **工艺与材料**：常用材料、现货标准件优先，避免定制件与逐件材料试验。

### 1.4 技术要求

1. 输出量以**力-时间历程**为设计对象，其主脉冲的峰值与脉宽应对标真枪主脉冲，并以台架实测定稿；
2. 释放在几何上由传动相位确定（不依赖闩锁或触发时序），保证逐发重复性；
3. 单发循环的力路径明确（§2.4），装配后组件静止位稳定、可重复，释放点逐发一致；
4. 全部零件可拆装维护，弹簧、缓冲器、轴承、齿轮均为现货标准件。

## 第 2 章 工况分析与总体方案

### 2.1 需求导致的工况

由第 1 章的需求可直接得到本装置的工况特征，这些特征决定了后续全部强度与寿命取值的依据。

**（1）能量形式与来源**

要求在无实弹、无外部气源条件下产生手枪级扰动，故能量只能来自机载**弹性储能**，由电机在装填过程中缓慢注入、在击发瞬间快速释放。储能元件取圆柱螺旋压缩弹簧（模具弹簧，现货等载荷分级标准件）。

**（2）单发循环的力学过程**

一个循环为：装填（弹簧储能）→ 释放（弹簧做功，运动组件加速）→ 飞行 → 撞击缓冲系统（减速停止）→ 回位。装置对外输出的力-时间历程由**运动组件撞击缓冲系统**这一段决定，其峰值与脉宽即第 1.4 条第 1 项的对标对象。

**（3）载荷性质（强度取值的依据）**

- **单向性**：全部机构单向旋转、单向受力（齿轮单向啮合、齿条单向推进、弹簧单向压缩），无交变对称循环载荷。齿轮齿根弯曲按脉动循环取值；齿面接触应力为恒压性质，寿命按循环次数取系数；
- **载荷谱**：每次装填一次完整加载与卸载（0 → 峰值 → 0），属脉动循环，循环次数 N = 设计寿命 = 2×10⁴；
- **冲击性质**：装填为伺服位置模式可控斜坡（齿条推力从零线性增长），仅逐齿进入啮合时有微小冲击，使用系数 KA 取 1.1（平稳驱动偏轻微冲击档）；
- **速度水平**：节圆线速度约 0.23 m/s（极低速），动载系数 KV 取 1.05（8 级精度低速区）。

**（4）环境与安装工况**

安装于运动中的机械臂末端：装置可能处于任意姿态（重力沿轨道方向的分量随之变化，装配条件须据此设定静止定位力）；供电 24 V；温升由低占空比脉冲工况决定。

### 2.2 总体方案与方案选定

**（1）时序方案：不完全齿轮（半齿轮）+ 齿条**

电机经传动齿轮对带动一个**切出齿缺的不完全齿轮**，其啮合段推动齿条（连同运动组件）压缩击发弹簧；转到齿缺段时齿条与齿轮**几何脱开**，运动组件被弹簧弹射加速，撞击缓冲系统。

选定理由：释放时刻由齿轮相位唯一确定（无闩锁、无触发时序误差，逐发重复）；每转一发，连发时无归位死区；释放边界由齿缺的加工位置决定，可用装配对准。

**（2）储能与发射方案：压缩螺旋弹簧驱动运动组件**

运动组件质量 m 经弹簧加速到撞击速度 v 后撞击缓冲系统；缓冲系统在刹停段把该动量传给机架，大小等于 m·v，由动量定理确定，与缓冲过程细节无关（完整循环的受力账见 §2.4）。

**（3）缓冲方案：液压缓冲器 + 定位弹簧并联**

以液压缓冲器（速度型阻尼）吸收每发动能、并把脉冲峰值与脉宽控制在需要范围内；另设两根**定位弹簧**与缓冲器并联，承担三项职责：静止定位（把运动组件顶在静止基准上，保持缓冲器杆与受力板之间的间隙）、缓冲起点确定（以预压给出刹停起始力）、停后回位。

选定理由：纯液压缓冲器在低阻尼档下需要 5.6 mm 以上行程（见 §5.2 对照计算），接近其 7 mm 行程极限，且无回位能力；并联定位弹簧后，静止位由硬基准确定、与弹簧刚度无关，回位有确定力源。

**（4）传动方案：电机 → m1 z25 齿轮对（1:1）→ 同轴 m1 z18 扇区齿轮 → 齿条**

z25 齿轮对为 1:1 等径传动，中心距 25 mm，其作用是给电机轴线相对半齿轮轴**布局偏置**（电机无需压在齿条正上方）；半齿轮由 m1 z18 毛坯切出（齿顶圆约 Φ20，小于同轴 z25 的 Φ27，套装不干涉）。

**（5）总体分层**

| 层 | 元件 | 功能 | 可调参数 |
|---|---|---|---|
| 扰动层 | 运动组件（0.55 kg） | 决定冲量 I = m·v | 组件质量 |
| 储能层 | 击发弹簧 ×2 | 决定撞击速度与行程 | 弹簧规格（行程由齿轮离散锁定） |
| 时序层 | 半齿轮 + 齿条 | 每转一发、几何脱齿释放 | 扇区齿数 |
| 动力层 | 伺服电机 | 装填与节奏控制 | 转速、圈数 |
| 缓冲层 | 液压缓冲器 + 定位弹簧 ×2 | 决定脉冲峰值、脉宽与回弹 | 缓冲器型号、定位弹簧刚度 |
| 传动层 | z25 齿轮对 1:1 | 等扭矩传动与布局偏置 | 齿数（同径约束） |

### 2.3 参数分配（冲量—速度—质量—能量—行程—刚度）

**（1）撞击速度 v 的确定**

撞击速度受两头约束：缓冲器允许的冲击速度范围（RB1007 为 0.05 到 5 m/s）；主脉冲宽度要求。匀减速模型下脉宽 t ≈ 2s/v（s 为刹停深度），真枪主脉冲为 3.5 ms 量级、缓冲器行程 7 mm，取 v ≈ 3.2 m/s 时可得 3 到 5 ms 的脉宽，落在此窗口内（回代校核后取 v = 3.19 m/s，见本节第 (6) 条）。

**（2）运动组件质量 m**

```
m = I / v = 1.75 / 3.19 = 0.549 kg       ……(2-1)
```

取设计点 **m = 0.55 kg**，质量窗口 0.50 到 0.70 kg（结构实称落入窗口即可，冲量随实称按 I = √(2Em) 标定，窗口内的指标浮动范围见 §12.3）。

**（3）行程 S 的确定**

行程不能连续取值：不完全齿轮的啮合段是整数个齿，且实际啮合量比整齿数多一个重合度（详细推导见第 6 章）：

```
S = (n + εα) · π · m        ……(2-2)
n = 6（啮合段完整齿数），m = 1.0 mm（模数），εα = 1.755（重合度，见 §6.2）
S = (6 + 1.755) × π × 1.0 = 24.36 mm        ……(2-3)
```

**（4）每发能量 E**

```
E = ½ · m · v² = ½ × 0.55 × 3.19² = 2.80 J       ……(2-4)
```

**（5）击发弹簧总刚度需求**

```
k总 = 2E / S² = 2 × 2800 / 24.36² = 9.44 N/mm       ……(2-5)
```

**（6）分配结果的自洽校核**

选定现货弹簧为两根 TF（轻小负荷）系列 YEL-14-75 并联，每根 4.71 N/mm，总刚度 k总 = 9.42 N/mm（计算与选型见第 3 章）。以此回代：

```
每发能量 E = ½ · k总 · S² = ½ × 9.42 × 24.36² = 2795 N·mm = 2.80 J
撞击速度 v = √(2E/m) = √(2 × 2.80 / 0.55) = 3.19 m/s
单发冲量 I = m·v = 0.55 × 3.19 = 1.75 N·s        ✓ 与 §1.2 需求一致
```

**（7）加速度与加速段时长**

运动组件在弹簧作用下的运动为简谐振动的一个四分之一周期：

```
角频率 ω = √(k总/m) = √(9420/0.55) = 130.9 rad/s
加速段时长 T = (π/2)/ω = 0.0120 s = 12.0 ms        ……(2-6)
加速段终速校核 v = S·ω = 24.36 × 130.9 = 3189 mm/s = 3.19 m/s ✓
```

### 2.4 单发工作循环（时序）

| 阶段 | 动作 | 时长量级 | 载荷特征 |
|---|---|---|---|
| 1 装填 | 半齿轮啮合齿条，推动运动组件压缩击发弹簧 24.36 mm | 100 ms（4 Hz）至任意慢（单发） | 齿条推力 0 → 229 N 线性增长 |
| 2 释放 | 齿缺段到达，齿条与齿轮脱开，组件被弹簧弹射 | 12.0 ms（加速段） | 弹簧力 229 N → 0 |
| 3 飞行 | 组件自由飞行至缓冲器杆与受力板接触 | 约 0.3 ms | 惯性 |
| 4 缓冲 | 液压缓冲器与定位弹簧并联吸收 2.80 J，刹停并回弹 | 2.6 到 4.3 ms | 峰值估 0.6 到 1.4 kN，台架实测 |
| 5 回位 | 定位弹簧与缓冲器内置复位弹簧推组件回静止位 | 约 25 ms | 二次冲击约 5% 主冲击 |

**机架受力说明**：加速段（阶段 2）中击发弹簧的反作用顶机架向前，与刹停段（阶段 4）缓冲系统顶机架向后的冲量大小相等、方向相反，整机为封闭系统，一个完整循环内的净冲量为零。装置复现的是手枪后坐中的**内部往复撞击分量**（气动仿真枪亦属此类），不产生弹丸与燃气那样的离体动量；对外表述与论文引用一律按此口径（第 11 章列出对外表述与校准路径）。

## 第 3 章 击发弹簧计算与选型

### 3.1 刚度需求

**已知**：每发能量 E = 2.80 J，行程 S = 24.36 mm（式 2-3），总刚度 k总 = 2E/S²。

```
k总 = 2 × 2795 / 24.36² = 9.42 N/mm       ……(3-1)
```

采用两根并联（等载荷分级标准件的现货规格所限，且两根并联可使推力对称、便于中间布置缓冲器）：

```
每根刚度 = 9.42 / 2 = 4.71 N/mm
总峰值力 = k总 · S = 9.42 × 24.36 = 229 N（每根 115 N）      ……(3-2)
```

### 3.2 选型

由模具弹簧等载荷分级标准件表（TF 轻小负荷系列，颜色标识黄色）选 **外径 14、内径 7、自由长 75（型号 YEL-14-75）**，每根刚度 4.71 N/mm，两根并联总刚度 9.42 N/mm。

选型依据：等载荷分级原理——同一外径的最大载荷标准化，刚度随自由长变化，同外径下刚度与自由长成反比。本规格由所需刚度 4.71 N/mm 在表中查得（同系列同外径的外径 14 一行中，自由长 75 对应刚度 4.71 N/mm），并满足外径小于活块宽度、两根并排可容纳的布置要求。

弹簧规格（厂家样本）：

| 项目 | 数值 |
|---|---|
| 外径 / 内径 | 14 mm / 7 mm |
| 自由长 FL | 75 mm |
| 刚度 k | 4.71 N/mm（0.48 kgf/mm） |
| 密着高 | 33.80 mm |
| 30 万次使用次数档额定压缩量 / 额定负荷 | 37.50 mm / 176.50 N（18 kgf） |
| 50 万次档 | 33.80 mm / 156.90 N（16 kgf） |
| 100 万次档 | 30.00 mm / 137.30 N（14 kgf） |

### 3.3 校核

**（1）工作压缩量对额定值**

```
S / 额定压缩量（30 万次档）= 24.36 / 37.50 = 65% < 100% ✓
S / 额定压缩量（100 万次档）= 24.36 / 30.00 = 81% < 100% ✓      ……(3-3)
```

本机设计寿命 2 万发，低于 30 万次档一个数量级，按 30 万次档校核已含充足余量。

**（2）工作负荷对额定负荷**

```
每根工作负荷 = 4.71 × 24.36 = 115 N
115 / 176.50 = 65%（30 万次档）< 100% ✓      ……(3-4)
```

（样本中同一外径段内额定负荷为常数，各行给出的压缩量即"达到该额定负荷所需的压缩量"，故用负荷之比与用压缩量之比等价。）

**（3）压缩率对寿命线**

```
压缩率 = S / FL = 24.36 / 75 = 32.5% < 40% ✓      ……(3-5)
```

**（4）密圈校核（压缩后不得压并）**

```
压缩后长度 = FL − S = 75 − 24.36 = 50.64 mm > 密着高 33.80 mm ✓      ……(3-6)
```

**（5）储能校核**

```
E = ½ · k总 · S² = ½ × 9.42 × 24.36² = 2.80 J，与 §2.3 需求一致 ✓
```

**结论**：击发弹簧 YEL-14-75 两根并联，在工作点 24.36 mm / 每根 115 N 下各项均低于标准件额定值，满足强度与寿命要求。

### 3.4 装填载荷联动

齿条推力等于弹簧力（齿条直接与半齿轮啮合）：

```
齿条峰值推力 F = k总 · S = 229 N      ……(3-7)
半齿轮节圆半径 r = m·z/2 = 1.0 × 18/2 = 9 mm（见第 6 章）
半齿轮轴峰值转矩 T = F · r = 229 × 9 = 2061 N·mm = 2.06 N·m      ……(3-8)
电机端峰值转矩（计入传动效率 0.9）= 2.06 / 0.9 = 2.29 N·m      ……(3-9)
推程平均转矩 = (0 + 2.06)/2 / 0.9 = 1.15 N·m
```

以上结果供第 7 章（轴系）与第 8 章（电机）校核使用。

## 第 4 章 定位弹簧计算与选型

### 4.1 功能需求

定位弹簧与液压缓冲器并联装在运动组件上，承担三项职责：

1. **静止定位**：把运动组件顶在静止基准（齿条啮合位或限位）上，使静止位有定义，并保持缓冲器杆与受力板之间 0 到 1 mm 的间隙；
2. **缓冲起点确定**：以预压量给出刹停起始力与位置；
3. **停后回位**：把组件从刹停位置推回静止位，使下一发可被齿条捕获。

**受力需求（静止定位）**：装置安装于机械臂末端，可能处于任意姿态。极限姿态下（轨道方向竖直）运动组件自重沿轨道方向的分量为

```
F_g = m·g = 0.55 × 9.81 = 5.4 N      ……(4-1)
```

导轨采用直线滚子导向，滚动阻力为 1 N 量级（可忽略），故定位压紧力需大于 F_g 并留余量，取设计值 10 到 20 N。

### 4.2 选型与校核

按同系列标准件选 **外径 8、内径 4、自由长 35（型号 YEL-8-35）**，每根刚度 4.31 N/mm，两根并联总刚度 8.62 N/mm；密着高 15.80 mm；30 万次档额定压缩量 17.50 mm / 额定负荷 78.50 N（8 kgf）。

**（1）静止压紧力**

```
预压 1 到 2 mm => 压紧力 = 8.62 × (1 到 2) = 8.6 到 17.2 N
判据：> F_g = 5.4 N（式 4-1），余量 1.6 倍以上 ✓      ……(4-2)
```

**（2）工作压缩量与寿命**

刹停终点组件继续后移（刹停深度 3.2 到 5.2 mm，见 §5.2），定位弹簧的最大工作压缩量为预压加刹停深度：

```
最大工作压缩量 = 2 + 5.2 = 7.2 mm
工作负荷 = 4.31 × 7.2 = 31 N
31 / 78.50 = 40%（30 万次档）< 100% ✓      ……(4-3)
```

**（3）密圈校核**

```
压缩后长度 = 35 − 7.2 = 27.8 mm > 密着高 15.80 mm ✓      ……(4-4)
```

**（4）回位能力**

回位阻力为缓冲器内置复位弹簧（4.22 到 6.86 N）的反向作用与滚子滚动阻力（1 N 量级）；定位弹簧在停点处的推回力为 8.62 × (2 + 5.2) = 62 N，远大于回位阻力，回位可靠。回位行程 5 到 7 mm，按简谐近似时间约 20 到 30 ms，在 4 Hz（周期 250 ms）的连发节奏内充裕。

**结论**：定位弹簧 YEL-8-35 两根并联（总刚度 8.62 N/mm），预压 1 到 2 mm，静止压紧力 8.6 到 17.2 N 满足极限姿态定位要求，压缩量与负荷均低于标准件额定值。

## 第 5 章 缓冲系统计算与选型

### 5.1 缓冲器选型与校核

**设计要求**：吸收每发动能 E = 2.80 J；撞击速度 v = 3.19 m/s；当量质量 m = 0.55 kg；行程尽量短。

**选型**：SMC RB1007 液压缓冲器（M10×1.0）。规格（厂家手册）：

| 项目 | 数值 |
|---|---|
| 行程 | 7 mm |
| 最大吸收能量 | 5.88 J/次 |
| 允许冲击速度 | 0.05 到 5 m/s |
| 当量质量范围 | 0.07 到 1.5 kg |
| 内置复位弹簧力 | 4.22 到 6.86 N |
| 本体尺寸 | 全长 53.7 mm、本体 46.7 mm、螺纹段 39 mm、活塞杆径 Φ3 |

**四项校核**：

**（1）吸收能量**

```
E / 额定 = 2.80 / 5.88 = 48% < 100% ✓      ……(5-1)
```

**（2）当量质量**（定义 Me = 2E/v²，本机构无外加推力）

```
Me = 2 × 2.80 / 3.19² = 0.55 kg，落在 0.07 到 1.5 kg 窗口内 ✓      ……(5-2)
```

**（3）冲击速度**

```
v = 3.19 m/s，为上限 5.0 m/s 的 64% ✓      ……(5-3)
```

**（4）使用频率**

```
持续使用上限 70 次/分（约 1.2 Hz）；本机单发为主，速射 1 到 4 Hz 为秒级短爆，
在散热允许范围内，不触发持续频率限制 ✓      ……(5-4)
```

**结论**：RB1007 四项校核全部通过，选型成立。

### 5.2 刹停能量核算

**模型**：运动组件以 v 撞入，缓冲器与定位弹簧并联共同吸收动能直至停止。设阻尼器在刹停过程中的平均阻力为 Fd，刹停深度为 s，定位弹簧预压 x₀ = 1 到 2 mm（取 1.5 mm 计算），能量守恒：

```
E = Fd·s + ½·k总·[(x₀ + s)² − x₀²]      ……(5-5)
展开：E = ½·k总·s² + (Fd + k总·x₀)·s
k总 = 8.62 N/mm（定位弹簧，第 4 章），E = 2800 N·mm
解方程 4.31·s² + (Fd + 12.9)·s − 2800 = 0
```

| 阻尼平均阻力 Fd | 刹停深度 s | 行程余量（7 − s） | 停点定位弹簧储能 | 回弹速度 | 二次冲击占比 |
|---|---|---|---|---|---|
| 500 N | 5.23 mm | 1.77 mm | 0.19 J | 0.82 m/s | 6.6% |
| 650 N | 4.12 mm | 2.88 mm | 0.13 J | 0.68 m/s | 4.5% |
| 840 N | 3.23 mm | 3.77 mm | 0.09 J | 0.56 m/s | 3.1% |

**对照（取消定位弹簧、纯液压缓冲）**：500 N 档刹停深度 = E/Fd = 2800/500 = 5.6 mm，仍在 7 mm 行程内但余量仅 1.4 mm；阻尼低于 470 N 时即逼近行程极限（400 N 档刹停深度 7.0 mm，等于全行程）。故定位弹簧并非兜底必需件，但**阻尼档位须设下限**（见 §5.5），且回位必须有独立力源。

**结论**：实际阻尼预计处于 650 到 840 N 档（速度型阻尼在 3.19 m/s 高速端阻力偏大），刹停深度 3.2 到 5.2 mm，行程余量 1.8 到 3.8 mm，**组件停稳前缓冲器不得到底**——该条列为台架第一验收项（验收方法：测停稳后活塞杆剩余露出量）。

### 5.3 峰值力与脉宽

**峰值力**：液压缓冲器为速度型阻尼，初段速度高（3.19 m/s）时阻力高于平均值。厂家手册未给出最大阻力字段，按同类产品特性估计峰值在 0.6 到 1.4 kN 量级；框架按 2000 N 短脉冲校核，余量充足，**峰值台架实测定稿**。

**脉宽**（匀减速模型）：

```
按实际刹停深度 3.2 到 5.2 mm：t = 2s/v = 2.0 到 3.3 ms      ……(5-6)
按全行程上限：t = 2 × 7 / 3.19 = 4.4 ms
```

讨论：参考力曲线的主脉冲（真枪套筒撞击机匣）为峰值 875 N、宽度 3.5 ms，按本设计冲量 1.75 N·s 缩放后为峰值 589 N、宽度 3.5 ms。本装置主脉冲 2.0 到 4.4 ms、峰值 0.6 到 1.4 kN，与缩放后的参考主脉冲同档（峰值略高、宽度略窄），衰减可通过选择小一号缓冲器型号或调整阻尼档位实现，**台架实测后定稿**。

### 5.4 回弹与二次冲击

刹停点处定位弹簧储能（表 5.2）释放，组件回弹速度为 0.56 到 0.82 m/s，对应二次冲击能量：

```
E₂ = ½·m·v回² = 0.09 到 0.19 J，为主冲击的 3.1% 到 6.6%      ……(5-7)
```

回弹速度低、二次冲击占比小，这是定位弹簧选用软规格（4.31 N/mm）带来的直接收益：弹簧越软，停点储能与回弹越小。回位所需时间约 20 到 30 ms，在连发周期内可完成并被下一循环齿条捕获。

### 5.5 阻尼档位下限

由 §5.2 的对照计算，取消定位弹簧分担后，刹停能量全部由缓冲器吸收：

```
刹停深度 s = E/Fd ≤ 7 mm（不计定位弹簧贡献，偏安全）
Fd ≥ E/7 = 2800/7 = 400 N
取余量 1 mm 以上：Fd ≥ E/6 = 467 N
```

**结论**：缓冲器在 3.19 m/s 处的平均阻力不得低于 450 N（推荐 500 到 650 N），列为装配验收项；台架实测若低于该下限，须换用更大一号缓冲器或更换阻尼介质。

## 第 6 章 不完全齿轮-齿条传动计算与选型

### 6.1 传动链与名义载荷

**传动链**：伺服电机（Φ6 输出轴）→ m1 z25 传动齿轮对（1:1）→ 同轴的不完全齿轮（由 m1 z18 毛坯切出）→ 齿条（固定在运动组件顶面）。

**名义切向力**（由击发弹簧峰值力经齿条传递）：

```
齿条推力 F = k总 · S = 9.42 × 24.36 = 229 N（第 3.4 节式 3-7）
半齿轮节圆半径 r = m·z/2 = 1.0 × 18 / 2 = 9 mm
半齿轮轴转矩 T = F · r = 229 × 9 = 2061 N·mm      ……(6-1)
齿条副切向力 Ft₁ = F = 229 N      ……(6-2)
齿条副径向力 Fr₁ = Ft₁·tanα = 229 × tan20° = 83 N      ……(6-3)
```

**工况载荷谱**：每发一次脉动加载（0 → 229 N → 0），循环次数 N = 2×10⁴；单向旋转、单向受力，无交变载荷（第 2.1 节认定）。

### 6.2 不完全齿轮的啮合量与行程

不完全齿轮的啮合段不是整数个齿就结束：一对齿从进入接触到退出接触要走过整个实际啮合线，故实际行程比"整齿数×齿距"多出一个重合度对应的长度。

**（1）啮合线与接触起止点**

渐开线齿廓上任一点的公法线都切于基圆，故全部接触点落在同一条直线上——过节点 P、与节线成 α 角、切于基圆的啮合线。节点处节圆半径 r = 9 mm，基圆半径 r_b = r·cosα = 8.4575 mm，齿顶圆半径 r_a = r + m = 10 mm。

接触起点 A 在齿条齿顶线（高于节线 m）与啮合线的交点上，直角三角形 A-F-P 中 AF = m、∠APF = α：

```
接近段 g_a = AP = m / sinα = 1 / sin20° = 2.924 mm      ……(6-4)
```

接触终点 E 在齿轮齿顶圆与啮合线的交点上，直角三角形 O1-N1-E 中 N1E = √(r_a² − r_b²)，PN1 = r·sinα：

```
退出段 g_r = PE = √(10² − 8.4575²) − 9 × sin20° = 5.335 − 3.078 = 2.258 mm      ……(6-5)
实际啮合线长 g = g_a + g_r = 2.924 + 2.258 = 5.182 mm      ……(6-6)
```

**（2）基节与重合度**

齿轮转过一个齿距角 2π/z 时，接触点在啮合线上前进 r_b·2π/z，代入 r_b = r·cosα、r = m·z/2：

```
基节 p_b = r_b · 2π/z = π·m·cosα = 3.1416 × cos20° = 2.952 mm      ……(6-7)
重合度 εα = g / p_b = 5.182 / 2.952 = 1.755      ……(6-8)
```

εα 的物理含义是同时参与啮合的齿对数，也等于"一对齿从入啮合到出啮合多走的齿距数"。

**（3）不完全齿轮的实际行程与转角**

接触点沿啮合线前进的速度为 r_b·ω，故一对齿完成整个接触过程经历转角 g/r_b，折算到节圆上的弧长（即齿条被推进的长度）：

```
一对齿的行程 = r·(g/r_b) = g/cosα = εα·π·m = 1.755 × π × 1.0 = 5.51 mm
不完全齿轮的实际行程 S = n·π·m + εα·π·m = (n + εα)·π·m      ……(6-9)
取 n = 6：S = (6 + 1.755) × π × 1.0 = 24.36 mm      ……(6-10)
对应转角 θ = (n + εα)·360/z = 7.755 × 360/18 = 155.1°      ……(6-11)
```

**（4）扇区齿数与齿缺**

扇区实际齿数须覆盖整个啮合过程，即不少于 n + ceil(εα) = 8 齿；取 **8 齿（160°）**，齿缺 **200°**。若只做 6 齿，最后一个齿会在退出接触前提前脱啮，实际行程短于设计值。

**（5）释放窗校核**（活块弹飞不追齿）

```
齿缺窗时间（4 Hz，周期 250 ms）= 250 × 200/360 = 139 ms
组件弹飞 + 缓冲全程约 15 到 20 ms << 139 ms ✓      ……(6-12)
```

### 6.3 齿面接触强度校核

**校核公式**（GB/T 3480 手册式，全系数法）：

```
σH = ZB·σH0·√(KA·KV·KHβ·KHα)                          ……(6-13)
σH0 = ZH·ZE·Zε·√[(Ft/(d₁·b))·(u±1)/u]                 ……(6-14)
许用应力：σHP = σHlim·ZN·ZL·Zv·ZR·ZW·ZX / SH          ……(6-15)
```

**系数逐项取值（齿条副）**：

| 系数 | 取值 | 依据 |
|---|---|---|
| KA | 1.1 | 伺服可控斜坡驱动、脉动加载、单向；平稳驱动偏轻微冲击档 |
| KV | 1.05 | 节圆线速度 v线 = π·d₁·n/60000 = π×18×240/60000 = 0.226 m/s，8 级精度低速区 |
| KHβ | 1.1 | b/d₁ = 10/18 窄齿、无齿向修形，简化法取小值 |
| KHα | 1.1 | 8 级精度、重合度低；FtH/b = 229/10 = 22.9 N/mm |
| ZB | 1.0 | 齿条副无单对齿修正问题，保守取 1 |
| ZH | 2.495 | 标准 20° 无变位：ZH = √(2/(sinα·cosα)) |
| ZE | 189.8 | 钢-钢弹性系数查表 |
| Zε | 0.677 | Zε = 0.25 + 0.75/εα = 0.25 + 0.75/1.755 |
| u | ∞ | 齿条按 u 趋于无限处理，(u+1)/u → 1 |
| σHlim | 550 MPa | 45 钢/S45C 调质，质量等级 MQ 线查取 |
| ZN | 1.55 | N = 2×10⁴ 次，调质钢接触寿命系数 |
| ZL·Zv·ZR·ZW·ZX | 均取 1.0 | 脂润滑低速（v < 1 m/s）无油膜修正、齿面常规加工、无尺寸效应 |
| SH | 1.1 | 一般工业齿轮可靠度档 |

**代入计算**：

```
Ft/(d₁·b) = 229/(18 × 10) = 1.272 N/mm²
根号内 = 1.272 × 1 = 1.272
σH0 = 2.495 × 189.8 × 0.677 × √1.272 = 320.5 × 1.128 = 361.5 MPa
σH = 1.0 × 361.5 × √(1.1 × 1.05 × 1.1 × 1.1) = 361.5 × 1.182 = 427 MPa
σHP = 550 × 1.55 / 1.1 = 775 MPa
```

**校核结论**：

```
σH = 427 MPa < σHP = 775 MPa ✓
安全系数 SH实 = 775 / 427 = 1.81 > SHmin（一般可靠度 1.0 到 1.1）✓
```

### 6.4 齿根弯曲强度校核

**校核公式**（方法二，εα < 2 适用）：

```
σF = σF0 · KA · KV · KFβ · KFα                          ……(6-16)
σF0 = (Ft/(b·m)) · YFa · YSa · Yε                       ……(6-17)
许用应力：σFG = σFlim · YST · YNT · YδrelT · YRrelT · YX / SF      ……(6-18)
```

**系数逐项取值（半齿轮 z18）**：

| 系数 | 取值 | 依据 |
|---|---|---|
| YFa | 2.91 | 齿形系数，z18、20° 无变位查图 |
| YSa | 1.53 | 应力修正系数（齿根过渡应力集中）查图 |
| Yε | 0.677 | Yε = 0.25 + 0.75/εα（与 §6.3 一致） |
| KFβ | 1.1 | 由 KHβ 换算（窄齿 b/h 小），取与 KHβ 同档 |
| KFα | 1.1 | KFα = KHα |
| σFlim | 250 MPa | 调质钢 MQ 线查取 |
| YST | 2.0 | 试验齿轮应力修正（标准规定值） |
| YNT | 1.6 | 弯曲寿命系数，N = 2×10⁴、脉动循环 |
| YδrelT·YRrelT·YX | 均取 1.0 | 常规齿根圆角/表面/无尺寸效应 |
| SF | 1.25 | 一般工业可靠度档 |

**代入计算**：

```
Ft/(b·m) = 229/(10 × 1.0) = 22.9 MPa
σF0 = 22.9 × 2.91 × 1.53 × 0.677 = 69.0 MPa
σF = 69.0 × (1.1 × 1.05 × 1.1 × 1.1) = 69.0 × 1.398 = 96.5 MPa
σFG = 250 × 2.0 × 1.6 / 1.25 = 640 MPa
```

**校核结论**：

```
σF = 96.5 MPa < σFG = 640 MPa ✓
安全系数 SF实 = 640 / 96.5 = 6.6 > SFmin（1.25）✓
齿根弯曲不控制设计。
```

## 第 7 章 传动齿轮对与轴系计算与选型

### 7.1 传动齿轮对（z25，1:1）

**几何与载荷**：两轮同径 m1 z25，分度圆直径 d = 25 mm，中心距 a = m(z₁+z₂)/2 = 25 mm；齿宽 b = 10 mm、Φ6 孔、S45C。由半齿轮轴转矩 2061 N·mm 折算：

```
Ft₂ = 2T / d = 2 × 2061 / 25 = 165 N      ……(7-1)
Fr₂ = Ft₂·tanα = 165 × tan20° = 60 N      ……(7-2)
```

**接触强度校核**（凸-凸啮合，u = 1，(u+1)/u = 2，其余系数同 §6.3）：

```
σH = ZH·ZE·Zε·√(KA·KV·KHβ·KHα · Ft₂/(b·d₁) · 2)
   = 2.495 × 189.8 × Zε × √(1.1×1.05×1.1×1.1 × 165/(10×25) × 2)
Zε（z25 对 z25 之重合度）：g_a = g_r = √(13.5² − 11.746²) − 12.5×sin20° = 2.379 mm
   g = 4.758 mm，εα = 4.758/2.952 = 1.612，Zε = 0.25 + 0.75/1.612 = 0.715
σH = 2.495 × 189.8 × 0.715 × √(1.3976 × 0.66 × 2) = 338.6 × 1.358 = 460 MPa
SH实 = 775 / 460 = 1.68 ✓      ……(7-3)
```

**弯曲强度校核**（YFa = 2.65，YSa = 1.58，Yε = 0.715）：

```
σF0 = (165/10) × 2.65 × 1.58 × 0.715 = 49.4 MPa
σF = 49.4 × 1.398 = 69.1 MPa < σFG = 640 MPa，SF实 = 9.3 ✓      ……(7-4)
```

**结论**：z25 齿轮对接触与弯曲强度均满足要求（SH实 1.68、SF实 9.3）。

### 7.2 轴系结构与载荷

**结构**：半齿轮（z18 扇区）位于两轴承之间（简支），从动齿轮（z25）装在同一轴伸出轴承之外的悬臂段上。该布置把精度关键的半齿轮放在两支承之间，只传动矩的从动轮置于悬臂段以节省轴向长度。

**轴承受力点与载荷作用点**（由结构确定）：轴承跨距 L = 45 mm；悬臂长 a = 12 mm；半齿轮中心线到最近轴承距离 a₁ = 15 mm（另一端 b₁ = 30 mm）。

**合成载荷**（每处啮合的切向力与径向力合成）：

```
半齿轮-齿条处：F₁ = √(Ft₁² + Fr₁²) = √(229² + 83²) = 244 N      ……(7-5)
从动齿轮处：  P  = √(Ft₂² + Fr₂²) = √(165² + 60²) = 176 N      ……(7-6)
```

### 7.3 中间轴强度校核

**弯矩计算**（简支跨 + 悬臂端弯矩法）：

```
跨内最大弯矩（半齿轮载荷位于跨内 15/30 处）：M = F₁·a₁·b₁/L = 244 × 15 × 30/45 = 2440 N·mm
悬臂根部弯矩：M₂ = P·a = 176 × 12 = 2112 N·mm
取较大者 M = 2440 N·mm 与跨内最不利组合（按 300 N 等效载荷估）复核：
M ≈ 300 × 45/4 = 3375 N·mm
```

**截面模量与应力**（Φ6：W = π·d³/32 = 21.2 mm³；Wt = π·d³/16 = 42.4 mm³）：

```
弯曲应力 σb = M / W = 3144 / 21.2 = 148 MPa      ……(7-7)
扭转剪应力 τ = T / Wt = 2061 / 42.4 = 48.6 MPa      ……(7-8)
弯扭合成（脉动循环，折合系数 α = 0.6）：
σca = √(σb² + (α·τ)²) = √(148² + (0.6×48.6)²) = 151 MPa      ……(7-9)
```

**材料与结论**：

```
40Cr 调质：[σ-1] ≈ 340 MPa => S = 340/151 = 2.25 ✓      ……(7-10)
定：中间轴 Φ6、40Cr 圆棒（调质），强度满足要求。
```

### 7.4 中间轴刚度校核（三项挠度模型）

半齿轮-齿条啮合的错位由三项叠加而成，其中第三项是悬臂载荷使轴承处产生转角、带动整跨倾斜所致：

```
① 跨内弯曲（半齿轮处）：f₁ = F₁·a₁²·b₁²/(3·E·I·L)      ……(7-11)
② 悬臂段自身弯曲（从动齿轮处）：δ = P·a³/(3·E·I)      ……(7-12)
③ 悬臂载荷在轴承处转角：θ = P·a²/(2·E·I)，带动半齿轮处额外错位 = θ·d      ……(7-13)
其中 E = 2.06×10⁵ MPa；Φ6 的 I = π·d⁴/64 = 63.6 mm⁴
```

**代入（L = 45、a = 12、a₁ = 15、b₁ = 30、x = 15 mm）**：



| 项目 | Φ6（I = 63.6 mm⁴） | Φ8（I = 201 mm⁴） |
|---|---|---|
| 半齿轮-齿条啮合处挠度 | 0.044 mm | 0.014 mm |
| 占齿侧间隙（约 0.1 mm） | 约 44% | 14% |
| 从动齿轮处挠度 | 0.008 mm | 0.003 mm |

**评定**：啮合错位仍小于齿侧间隙，不会卡死；其后果是啮合长期偏向一侧齿面（摩擦与磨损偏大），对释放点的影响是整体平移 0.34% 的能量、且为系统偏差，可通过标定吸收，不影响逐发一致性。

**结论**：整机为实验设备（设计寿命 2×10⁴ 发、低速），取 **Φ6 光轴**（40Cr）；如后续出现啮合偏紧或齿面磨损偏快的迹象，将悬臂段或整轴改为 Φ8 即可把啮合处挠度降到 0.014 mm，该项为易更换件。

### 7.5 轴承选型

半齿轮轴两端各一深沟球轴承（内径 Φ6），承受径向力（两处啮合载荷的支承反力，量级 100 到 250 N），转速 ≤ 240 r/min，设计循环 2×10⁴ 转。选 **606ZZ**（内径 6、外径 17、基本额定动载荷 Cr ≈ 2.0 kN）：

```
当量动载荷 P = R ≈ 0.25 kN（无轴向力）
基本额定寿命 L₁₀ = (Cr/P)³ = (2.0/0.25)³ = 512 百万转
设计需求 = 2×10⁴ 转 = 0.02 百万转 => 寿命余量巨大 ✓      ……(7-14)
```

**结论**：轴系强度安全系数 2.10、刚度按上述评定可接受、轴承寿命余量巨大，轴系设计成立。

### 9.2 腕关节静载校核

```
静载力矩 M静 = 1.8 × 9.81 × 0.080 = 1.41 N·m

```

**结论**：腕关节静载占用过半、余量有限（第 1.3 节已列为边界条件）。**减小重心距离是最直接的改善途径**：重心由 80 mm 减到 40 mm 时静载力矩降至 0.71 N·m（占 28%），故结构设计应把质量较大的部件（运动组件、缓冲器、电机）尽量布置在靠腕轴一侧。

### 9.3 射击动态载荷与平台侧边界

刹停段缓冲系统向机架输出的峰值力为 0.6 到 1.4 kN（第 5.3 节，实测定稿），作用线为反坐力轴线。设反坐力轴线到腕轴的垂距为 d，则腕部承受的扰动矩为

```
M = F·d      ……(9-2)
d = 0.03 m 时：M = 18 到 42 N·m，超过腕关节峰值 7 N·m
```

该结果说明：**本机与机械臂之间的连接方式不能按刚性直连设计**。装置侧能做的两件事是：①把反坐力轴线与整机重心都尽量贴近腕轴（减小 d 与静载）；②把峰值力的量级控制在实测确认范围内（第 11 章）。平台侧需在枪/设备与法兰之间引入柔顺环节（弹性接口或关节柔顺控制），其参数由平台层另行设计——本机按"对外输出力-时间历程"设计，不承担接口层的设计。相关数据供平台侧使用。

### 9.4 平台负载预算

```
机械臂约 3.8 kg + 本机约 1.3 kg + 传感器约 0.3 kg = 5.4 kg
平台额定负载 8 kg => 余量约 2.6 kg ✓      ……(9-3)
```

**结论**：整机质量约 1.3 kg、平台负载预算有余量（约 2.6 kg）；腕关节静载占用 56% 到 73%，需按 §9.2 的布置原则进一步优化重心距离。

## 第 10 章 装配条件与验收指标

（实现方式由用户自定；验收时逐条核对）

1. **整体布置**：机架后墙固定受力板；液压缓冲器本体与两根定位弹簧都装在运动组件上，杆尖与弹簧端朝后顶受力板，三者并联；轴线平行于运动方向。
2. **液压缓冲器（RB1007）**：活塞杆全伸时杆尖与受力板留 0 到 1 mm 间隙；任何静止状态下杆不得受压（禁预压杆）；杆径仅 Φ3，安装须对中，偏载会弯杆；杆全伸露出 7 mm 等于行程，压到底时杆端与本体端面齐平，齐平后再撞即为金属硬碰。**组件停稳前缓冲器不得到底**（刹停余量 1.8 到 3.8 mm）——列为台架第一验收项，验收方法：测量停稳后活塞杆剩余露出量。
3. **定位弹簧**：两根 YEL-8-35 并联，各预压 1 到 2 mm（合计 8.6 到 17.2 N），兼三职——静止定位、缓冲起点确定、停后回位。
4. **击发弹簧**：两根 YEL-14-75 并联；允许从自由长零力起压缩；静止态微预压 0 到 0.5 mm（静力 0 到 5 N，刚抵住无间隙即可），预压只消除装填空程，不承担定位；**每发释放点 = 满压缩 24.36 mm 处**（几何确定）。
5. **静止力平衡条件**：组件静止时受定位弹簧静力 8.6 到 17.2 N（由结构的静止基准——齿条啮合位或限位，用户自定——承受）；**组件静止位漂移不大于 ±0.2 mm**。
6. **解耦条件**：任何静止状态下，定位弹簧有效预压变化不大于 ±0.2 mm、击发弹簧被动压缩不大于 0.5 mm、缓冲器杆间隙保持 0 到 1 mm；装配时按此三指标验收。
7. **释放边界对准**：齿缺边界（扇区 160° 走完那一点）必须对准活块压缩 24.36 mm 处。精度分两档：**绝对**对准 ±0.2 到 0.3 mm（两处啮合齿侧间隙累计，折算能量 ±2%，且单向驱动下为系统偏差、标定可吸收）；**重复性** ±0.1 mm（一发到下一发的位置一致性，由单向驱动的同侧齿面贴合保证）——逐发一致性的根本。
8. **装填链空间**：齿条随活块往复（行程 24.36 mm）的扫掠区，与电机外廓（约 28 × 78 mm，含线缆余量）之间最小间隙不小于 3 mm；电机居中布置时优先让电机轴向错开齿条行程带。
9. **齿轮装配**：z25 传动对中心距 25 mm（= m(z₁+z₂)/2）；侧隙与齿向对中按 8 级精度；齿面涂锂基脂；半齿轮与从动齿轮同轴串列、齿相位按装配标记对齐；齿条与半齿轮轴向对中误差 ≤ 1 mm（齿条宽 12、半齿轮宽 10 的设计容差）；传动齿轮 A 与电机输出轴采用夹紧式轮毂固定。
10. **轴系**：半齿轮位于两轴承之间、从动齿轮位于轴承外悬臂段；轴 Φ6、材料 40Cr 调质；两端轴承 606ZZ；轴向无载荷，预紧按常规；强度安全系数 2.25、啮合处挠度 0.044 mm（§7.4 评定）。
11. **击发弹簧端部**：弹射侧回弹敲击由端部垫片（聚氨酯垫圈）处理，指标为不对冲量与逐发一致性造成可测影响。

## 第 11 章 需实测确认项与校准路径

1. **缓冲器峰值力与低速段特性**：厂家手册无最大阻力字段，峰值（现估 0.6 到 1.4 kN）与刹停深度只能台架实测（框架按 2000 N 短脉冲校核已覆盖面）。

3. **弹药冲量基准**：5.8×21mm 弹的冲量 1.69 N·s（式 1-1）为公开资料加装药量估算，不确定度 ±15% 量级（物理上限 1.86 N·s）；有条件时以真枪实测或弹道摆校准。
4. **组件实称与冲量标定**：结构实称在 0.50 到 0.70 kg 窗口内时行程与储能不变、冲量按 I = √(2Em) 标定；超出窗口须重算弹簧刚度。
5. **回弹与二次冲击**：计算值 0.09 到 0.19 J（占主冲击 3% 到 7%），台架实测定稿。
6. **阻尼档位下限**：缓冲器在 3.19 m/s 处平均阻力不得低于 450 N（§5.5），装配后实测确认。
7. **电机掉速与温升**：24 V 下高扭矩段 4 Hz 连发贴线、3 Hz 无压力；持续满速射的温升与掉速以台架实测为准（必要时升 48 V 供电）。
8. **齿面载荷复核**：用电机电流反推实际齿载，复核 §6.3、§6.4 的应力校核（尤其半齿轮-齿条副）。
9. **释放点重复性与齿隙影响**：首件按第 10.7 条验收；运行 1000 发后复测释放点，确认齿侧间隙未因磨损扩大。
10. **滚子导轨的长期表现**：滚子导向使摩擦可忽略（装配后以手推确认），但磨损、润滑与污染会改变摩擦与释放一致性，列入定期检查。
11. **对外表述口径**：本装置复现的是手枪后坐中的**内部往复撞击分量**（加速段弹簧反作用与刹停段缓冲力大小相等方向相反，一个完整循环净冲量为零），不产生弹丸与燃气那样的离体动量；论文、专利与对外答询一律按此口径表述，不写作"冲量生成器"。
12. **关节载荷与平台侧**：本机与机械臂的连接不得按刚性直连设计（§9.3），柔顺环节的参数由平台层设计并与本机的实测力-时间历程配套。

### 12.3 实物指标浮动范围

结构实称与装配公差会使实物指标在设计点附近浮动，估计范围如下。

**（1）冲量与撞击速度（随组件实称变化）**

行程与储能固定时，冲量由 I = √(2Em) 决定：

| 组件实称 | 撞击速度 v = √(2E/m) | 单发冲量 I | 相对设计点 |
|---|---|---|---|
| 0.50 kg | 3.35 m/s | 1.67 N·s | −5% |
| 0.55 kg（设计点） | 3.19 m/s | 1.75 N·s | — |
| 0.70 kg | 2.83 m/s | 1.98 N·s | +13% |

**（2）缓冲指标**

峰值力随撞击速度同向变化（速度高则阻尼力高），故 0.50 kg 实称时峰值与刹停深度偏大、0.70 kg 时偏小；刹停深度仍在 5.6 mm 以内（按 0.50 kg、500 N 阻尼档复算），不得到底的条件保持。

**（3）脉宽**

主脉冲 2.0 到 4.4 ms，随实际阻尼档位与刹停深度变化（第 5.3 节）。

**（4）逐发一致性（目标 ±5%）的主要影响因素**

| 因素 | 量级 | 处置 |
|---|---|---|
| 释放点重复性（含齿侧间隙） | 系统偏差约 ±2%（能量），重复性 ±0.1 mm | 单向驱动保证重复性；绝对偏差靠标定吸收（§10.7） |
| 弹簧自身迟滞与阻尼特性 | 2% 到 4% | 弹簧按 2 万发寿命工作（额定占用 65%），台架统计确认 |
| 缓冲器油液温度 | 阻尼力随温度漂移 | 连续射前预热或按温度修正标定 |
| 滚子导向摩擦 | 可忽略（设计值 1 N 量级） | 定期清洁与检查（第 11.10 条） |

**（5）对平台指标的传导**

腕部静载力矩 = 末端总重 × 重心距离（§9.2，随结构布置在 0.7 到 1.5 N·m 之间）；腕部射时扰动矩 = 缓冲峰值力 × 反坐力线垂距（§9.3），两项都随结构布置变化，须在结构定型后据实重算。

## 第 13 章 论文/专利写作素材

### 13.1 一句话定位（摘要可用）

面向无人平台后坐扰动抑制研究的、安装于机械臂末端的全电动手枪级后坐力-时间历程发生器：以"弹簧驱动运动组件撞击组合缓冲系统"产生可标定的力-时间历程，以"连续单向旋转不完全齿轮每圈一发、几何脱齿释放"保证释放时刻的确定性重复，以"液压缓冲器并联预压弹簧"控制脉冲形态与回位。

### 13.2 分层架构（技术方案总述素材）

| 层 | 元件 | 原理 | 决定指标 | 独立可调参数 |
|---|---|---|---|---|
| ① 扰动层 | 运动组件（0.55 kg） | 动量 I = m·v | 单发冲量 1.75 N·s | 组件质量（0.50 到 0.70 kg） |
| ② 储能层 | 击发弹簧 ×2 | 弹性势能 E = ½kS² | 行程 / 峰值力 / 撞击速度 | 弹簧规格（行程由齿轮离散锁定） |
| ③ 时序层 | 不完全齿轮 + 齿条 | S = r·θ，齿缺脱啮 | 每转一发、无归位死区 | 扇区齿数（8 齿） |
| ④ 动力层 | DM-S2325-1EC | 位置/速度双模式 | 射速、单发与连发 | 电机转速、圈数 |
| ⑤ 缓冲层 | RB1007 + 定位弹簧 ×2 | 液压阻尼与弹性储能并联 | 脉宽 / 峰值 / 回弹 | 缓冲器型号、弹簧刚度 |
| ⑥ 传动层 | m1 z25 齿轮对 1:1 | 等扭矩传动与布局偏置 | 传动效率与布置 | 齿数（同径约束） |

### 13.3 核心创新点（专利特征清单）

1. 分层解耦架构：扰动、储能、时序、动力、缓冲、传动各层参数独立可调；
2. 连续单向旋转不完全齿轮机构：啮合段压缩储能、齿缺段几何脱啮释放，每圈一发的无归位死区连发；释放时刻 = 齿轮相位（几何确定，无闩锁抖动）；
3. 单发/连发双模式：伺服转一圈停于齿缺位（零保持）或速度模式连续旋转；
4. 组合缓冲构型（液压缓冲器 + 预压定位弹簧并联）：定位弹簧三职责（静止定位、缓冲起点确定、停后回位），且其刚度由定位与回位需求决定、不再受刹停兜底约束，因而可选取较软规格以压低回弹与二次冲击；
5. 齿轮整齿离散约束设计法：行程 = (n + εα)·π·m 的离散锁定及其与储能、质量的反推设计流程（含不完全齿轮啮合量必须计入重合度的方法，可复用）；
6. 编码器释放角同步：以电机编码器相位确定释放时刻并输出触发脉冲，免外置释放传感器；
7. 现货等载荷分级弹簧选型 + 工况系数校核的工程方法。
