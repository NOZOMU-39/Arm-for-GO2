## 四、电源与急停
- 全电机统一 24V 母线，不降压；可调直流电源 0–60V/4000W（约 66A 档）级，覆盖 24V 与未来 48V；具体型号不记录
- 隔离模块给控制侧供电；12V 小电池经 OR 电路自动接管控制侧（**不供电机**）——急停/动力掉电后控制侧不死，能执行安全停止与记录
- 上电顺序：控制侧先上电→动力侧再上电→连接→安全启动流程
- 急停：遥控继电器**常闭触点串电机动力母线**（遥控断开＝硬切动力）；辅助触点把急停状态反馈给 PC/ESP32；软件收到后停发＋日志＋急停复位锁
- 所有电机**无抱闸**：急停断电即坠落，物理兜底（安全姿态＋支撑＋泡棉）不可省略

### IMU 选型（用户确认 2026-08-16）
- 厂商：HIPNUC 精浦科技，天猫旗舰店 hipnuc.tmall.com / 京东 mall.jd.com/index-16829568.html
- 用户确认：**两个 IMU 统一 HI12S2，串口+CAN 版本（MI1，UART+CAN 内置收发器）**；枪口端与基座端均为 HI12S2-MI1-000
- 关键性能（S2）：陀螺 ±4000°/s、加计 ±32g、20bit、3dB 带宽 80~400Hz、输出最高 1000Hz（UART/CAN）、零偏不稳定性 1.5°/h、加计 10ug；22×22×10mm、<8g、铝合金 CNC 外壳；抗振 ≤20g(58-600Hz)、抗冲击 2000g；供电 3.3~5.5V（内置 LDO）
- 接口/协议：CAN 125K/250K/500K/1M（默认 500K、CANopen、100Hz），支持二进制/CANopen/Modbus；UART 最高 1000Hz；支持外部触发同步（SYNC 延时 800µs）
- 开源友好：官方 GitHub `hipnuc/products`（协议库＋STM32/ROS/ROS2/Linux/MATLAB 例程，含 hipnuc_imu_can）；中文数据手册/指令手册公开
- 下单确认：MI1（UART+CAN）、6DoF 版、-000（Molex 接口）
- 排除记录：达妙 DM-IMU-L1（yaw 1h 零漂 12.686°，社区实测更差）；GY-H1（ICM42688+CAN 全开源但无零售渠道，备选自制）；北微 BW-IMU125（带宽 100Hz、量程 ±400°/s 不够）；维特 JY931（无 CAN）

### 无线链路与速率预算
- 现状（v2.1.3）：TCP 8888 批帧推送（客户端协商 0x0A13 启用）+ UDP 8889 订阅式推送（可选）；实测接收 750 帧/s 全通零丢失（受分析仪发送上限所限，**ESP32 真实接收上限未测出，≥750/s**）；发送方向 AP ~630/s；CAN 1Mbps 物理上限约 7400 标准帧/s
- 分场景帧率预算：慢速位控全关节 200Hz ≈2.4k；射击阻尼瞬间（基座 yaw 1kHz＋枪口 IMU 1kHz＋其余 200Hz）≈5.1k；全关节 1kHz 双向＋2 IMU 1kHz＝12k（CAN 物理不可能，需 CAN FD 或双总线）
- 结论：算法框架最终需要**无线 ≥5k 帧/s、CAN 预算 ≤6k**；分频段设计（yaw 相关 1kHz，其余 200~500Hz）；无线侧批帧打包＋可选 UDP 可到 3~5k+ 帧/s，方案待批准后实施

## 七、安全决策（完整，2026-08-16）
### 总体原则
- 三线并行：结构、硬件、软件同时推进；第一版以控制实现复杂度低为准
- 无抱闸 → 断电坠落 → 物理兜底不可省略
- 动现有代码/硬件前必须经用户同意

### 结构线
- 加强优先级：①Go2 背板与 X8 连接（加厚衬板 5~8mm 铝合金、螺栓 M5×4 以上＋防松、背板加筋）②大臂根部法兰（增厚或径向筋、转接件整体化）③小臂/腕（壁厚/截面加大控重、避免细颈）④末端护罩（摄像头/激光笔/枪座一体）
- 机械零点：每关节一组"凸点＋刻线"（0° 参考位），做在连接件上不依赖电机型号；找零 SOP＝断电/失能→人工低速转至凸点对齐→0x64 设零（V3 单发；V4 按 0x80→0x64→0x76）→记录档案；换新版 X8 沿用，档案版本＋1
- 限位两档：软限位（人工引导标定：转两端→记录→自动加裕度 max(5°, 行程×5%)）＋泡棉挡块（高密度聚氨酯 Shore 40~60A、行程两端、预压缩 3~5mm、结构胶＋压板）；金属硬限位列后续
- 安全姿态：收拢低势能＋末端有支撑

### 硬件线
- 供电分级与 12V 电池接管见第四节
- 急停接法与反馈见第四节
- ESP32 心跳看门狗：规格已交付，本期不落地（固件不动）

### 软件线（第一版）
- 显式状态机：断电→上电→手动待机→标定→就绪→运行→软急停→硬急停恢复；非法转换拒绝＋审计；进入运行必须经就绪
- 保守单关节软限位：档案 JSON（limMin/limMax/margin/calibDate/operator/version）；位置指令按目标检查、增量 0xA8 换算目标、单圈 0xA6 按减速比换算；V3 无掉电记忆→软限位与零点档案联动（零点失效时降级为"仅提示"或强制先归零）；只拦位置，速度/力矩靠限速限流
- 三档限速限流：标定 10%速/25%流、手动 30%速/50%流、自动 100%但设全局上限；默认手动＋低速＋软限位生效
- 确认锁：危险操作二次确认（写 ROM/设零/大位移大速度）＋模式锁（手动/自动）＋急停复位锁＋通信看门狗
- 软急停：不断电、停在当前位置（闭环保持；定义保持力矩上限与超时，超时提示回待机位）；人类可选"继续"（回手动模式，自动轨迹不续跑）或"重启回待机位"；程序与人类双向确认；人工触发可继续，看门狗/越限/报警触发默认只回待机位
- 硬急停恢复 SOP（每步程序门＋人类确认；恢复必须人类显式发起；任一步失败回异常态）：①确认物理与软件环境正常 → ②确认电机重新上电（供电 24V±10%、CAN 在线、无报警自检）→ ③归零（无断电记忆者先回凸点再设零；V4 按三步）→ ④回待机位（低势能安全姿态）
- 软启动时序：上电→控制侧→动力侧→连接→各关节小斜坡试探（限速限流）→凸点对零→就绪
- 看门狗三层：PC↔ESP32 心跳（暂缓）、CAN 反馈超时（2s 自动软急停）、UI 卡死隔离（安全逻辑独立线程）

## 八、关键协议结论（实测/手册，勿轻易推翻）
- 两代均无使能环节：上电直接发闭环指令；0x80 关闭/0x81 停止
- V3.91（2026-08-20 终版实测定论）：0x20 仅索引 1/2，无多圈掉电保存；0x60/0x61/0x62/0x63/0x64 实测全部无效（写 ROM 类被固件砍掉）；**旧款 X8/X6-S2 = 转子侧单圈绝对值编码器 + 固件内部维护多圈角（0x92 可读，回复在 D1~4 int32 0.01°/LSB，会被 0xA8 增量漂移成 ±360N）**；**0xA4 = 多圈绝对角目标，固件按「目标−当前」差值直接执行**（非最短路径、非单圈相位）；上位机终版方案：0x92 轮询校准 rotDeg 到固件角 + **E0 标定存凸点固件角（含圈号，非相位——存相位发 0° 会偏 60°）** + 0xA4 发 R_t=E0+out2rot(deg)；12 条踩坑全记录见 电机上位机开发\技术归档.md「问题 E」；0x9C D6~7＝16 位编码器脉冲（相位源）；0xA1 力矩在 D4~5；0x79 改 ID 对拨杆设 ID 的旧款无效
- V4.4：0x20 共 8 索引，索引 4＝多圈掉电保存（置 1，掉电前自动保存，重启生效，失能时写）；0x9C D6~7＝输出轴角度 int16；0xA1 力矩在 D2~3；0x64 设零必须 0x80→0x64→0x76 三步，单发无效
- 两代均无全局方向反转指令（0xA6 spinDirection 仅单次运动）→方向一致性只能软件映射（注册表 dir 字段，X8-PRO 设反转）；一体化 FOC 换相线方案不可行
- 0x77/0x78 为抱闸松/锁指令（当前无抱闸电机，预留）
