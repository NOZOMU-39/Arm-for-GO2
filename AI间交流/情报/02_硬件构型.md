## 电源与急停

- 全电机统一 **24 V 母线**，不降压；可调直流电源 0–60 V/4000 W（约 66 A 档），覆盖 24 V 与未来 48 V；具体型号不记录。
- 隔离模块给控制侧供电；**12 V 小电池经 OR 电路自动接管控制侧（不供电机）**——急停/动力掉电后控制侧不死，能执行安全停止与记录。
- 上电顺序：控制侧先上电 → 动力侧再上电 → 连接 → 安全启动流程。
- 急停：遥控继电器**常闭触点串电机动力母线**（遥控断开＝硬切动力）；辅助触点把急停状态反馈给 PC/ESP32；软件收到后停发＋日志＋急停复位锁。
- 所有电机**无抱闸**：急停断电即坠落，物理兜底（安全姿态＋支撑＋泡棉）不可省略——兜底做法见 04。

## Jetson 主控硬件

- **模组**：NVIDIA 原装 Orin NX 16GB（p3767-0000）；**载板**：图为（TWOWIN）定制 T801（TWOWIN T801_MBPCB_V2.0）；系统 JetPack 6.2.2 / L4T R36.5，Ubuntu 22.04，128 GB NVMe。
- **CAN**：T801 有 1 路 CAN，但**无板载收发器**；当前走 **PCAN-USB**（0c72:000c，peak-linux-driver 8.20.0 make netdev），can0@1M 开机自启；板载 mttcan 已 blacklist，根治待收发器到货。
- **当前功耗档**：**40 W**（sudo nvpmodel -m 4）；重启后是否需要重设未最终定论，以 nvpmodel -q 为准。
- **禁更新约束（长期有效）**：停用 NVIDIA L4T 源、禁 apt-daily、hold 六内核包（display-kernel / kernel / dtbs / headers / oot-headers / oot-modules）；**AI 不得擅自升级 JetPack/L4T/内核/DTB/启动链/rootfs/BSP**。
- **已知硬件问题**：曾发生 GPU（nvgpu）SM machine check → oops → panic 卡死（ramoops 实锤，非冷死/非 WiFi）；当前 40W 档稳定；复现时抓 /sys/fs/pstore + journalctl -k + tegrastats。
- **网络**：实验室 192.168.31.x（有线 DHCP）或 192.168.137.x（热点）；arm-ip 查当前 IP 与栈状态。
- 登录、SSH、部署件、ROS2 包与运维细节见 Jetson_Orin_NX\AGENTS.md，本册不抄。
