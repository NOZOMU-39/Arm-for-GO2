# AI间交流

> 项目的情报交换站（不是使用说明书）——给参与本项目的 AI 同步情报用，也供你随时查看 AI 之间同步了什么。

## 这个目录是什么

| 文件/目录 | 内容 | 性质 |
|---|---|---|
| 情报.md | **目录页**：有哪些分册、各在哪、最后更新哪天 | 先读这一页，再按需翻分册 |
| 情报\ | 01 当前状态 / 02 硬件构型 / 03 通信与IMU / 04 安全决策 / 05 协议与文档 / 99 变更记录 | **长期**；同一事实只写一处 |
| 交接\ | 2026-11-06 前的旧交接文件 | **已停用**，留档勿删；接手不再写交接 |

## 你会怎么用到它

- **想知道 AI 之间同步了什么**：先看 情报.md 目录页，再读 01_当前状态；需要细节再翻对应分册（99 只查来历）。
- **AI 换班**：新对话读「领域 AGENTS → 情报目录页 → 01 → git log」即可接手，不再需要单独的交接文件。
- **删短期文件**：只有你能决定删不删。

## 两套文档的分工

- 每个开发侧目录的 README.md（给人）＋ AGENTS.md（给 AI）是**自足的使用说明书**，整个子目录可以单独拷走使用；模块细节都在那里。
- 本目录只放**跨模块、项目级**的结论与决策，不复制模块文档的细节。

> AI 的详细规则（进入顺序/更新纪律/99 的用法/接手顺序）见同目录 AGENTS.md。
