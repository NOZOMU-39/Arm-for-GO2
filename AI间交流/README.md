# AI间交流

> 项目的情报交换站（不是使用说明书）——给参与本项目的 AI 同步情报用，也供你随时查看 AI 之间交接了什么。

## 这个目录是什么

| 文件/目录 | 内容 | 性质 |
|-----------|------|------|
| `情报.md` | **目录页**：有哪些分册、各在哪、最后更新哪天 | 先读这一页，再按需翻分册 |
| `情报\` | 分册（01 当前状态 / 02 硬件构型 / 03 通信与IMU / 04 安全决策 / 05 协议与文档 / 06 变更记录） | **长期记忆**，同一事实只写一处 |
| （历史变更） | 查 `git log --oneline`（提交信息即摘要；记录.md 已于 2026-08-23 废弃删除） | — |
| `交接\` | AI 交接文件与临时文件（文件名即主题） | **短期**：新对话完成接手后，经你同意可删除 |

## 你会怎么用到它

- **想知道 AI 之间同步了什么**：先看 `情报.md` 目录页，需要细节再翻对应分册（`99_变更记录.md` 约 48 KB，平时不必读）；
- **AI 换班**：旧对话退休时在 `交接\` 写交接文件，新对话接手时读它——你只需说一句「让新对话接手 XX，走交接协议」；
- **删短期文件**：只有你能决定删不删。

> AI 之间的详细规则（进入顺序/更新纪律/交接协议）见同目录 `AGENTS.md`（AI 使用说明书）。
