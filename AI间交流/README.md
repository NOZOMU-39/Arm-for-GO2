# AI间交流

本目录唯一用途：让未参与用户对话的 AI 同步项目情报。

## 进入顺序
1. 读 README.md
2. 读 情报.md（当前事实）
3. 读 记录.md（历史变更）
4. 读 消息\ 里最新的交接文件（若有）

## 规则
1. 所有 AI 同级；本目录与论文主控体系无关
2. 情报.md 由各 AI 共同维护，事实变化即更新；补充/异议先写 消息\，重要变更并入 情报.md
3. 消息\ 按需使用：文件名即主题；**交接文件处理完后不删除**（保留供新对话恢复上下文），普通消息处理完删除
4. 情报更新须经用户确认：每次获得新信息，先问用户是否更新情报.md，同意后才写入
5. 内容只放本目录；根 README 只写项目使用说明（人类向），AI 向约定见项目根 `AGENTS.md`

## 对话交接
- 完整协议见项目根 `AGENTS.md` 的「对话交接协议」章节（一句话触发：接手方读领域 AGENTS.md → 情报 → git log → 向用户汇报确认；退休方写 消息\交接_*.md 并提交）。
- 交接文件模板：`消息\交接模板.md`。
