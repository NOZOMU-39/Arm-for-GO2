# AI间交流 — 协作说明（任何 AI 进入先读本文件）

## 规则
1. 进入先读：本文件 → 项目上下文.md → 安全需求.md → 决策与规范\
2. 开工前到 登记\ 写登记卡（AI 名/工作范围/收件箱路径）
3. 任务单由 Codex 投到 任务\收件箱\<你的AI名>\；你的回执/成果放 任务\发件箱\<你的AI名>\
4. 一个文件一个写者：只写自己的发件箱和自己的产物；公共文件（项目上下文/安全需求/决策包）由 Codex 维护，有修改建议写进回执
5. 开工/关键节点先查自己收件箱；完成后写回执
6. AI 内容只放本目录，不写根 README 和人类使用区

## 生命周期（2026-08-16）
- 收件箱只放未处理；任务完结即归档（Codex 负责）
- 发件箱交付物评审后由 Codex 移入 任务\归档\
- 归档保留 1 个月，超期删除（删除前建议先提交 git 兜底）
- 临时文件不进本目录（放系统 Temp，用完即删）
- 清理脚本：工具\清理归档.ps1（默认 dry-run 列清单，加 -Execute 才真正删除）
