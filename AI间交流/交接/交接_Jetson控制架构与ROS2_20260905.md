## 踩坑（重要）

- **tmux ops 会话每次 Jetson 重启后消失**——操作前先 `tmux has-session` 检查，无则重建；send-keys 到不存在的会话=静默失败（本次 ROS2 安装曾因此白等 8 分钟）
- **/tmp/claude 重启后被 systemd 重建为 root 所有**——nvidia 写不了会报"权限不够"——先 `sudo chown -R nvidia:nvidia /tmp/claude`
- **sudo 密码交互**：密码 `1`；远程 sudo 用 `echo '1' | sudo -S <cmd>`；tmux send-keys 发密码时若在 bash 提示符下发送会被吞（在 Password: 提示下才安全）——不确定就请用户手动输
- **ROS2 源**：清华镜像 `mirrors.tuna.tsinghua.edu.cn/ros2/ubuntu`；key 从 GitHub raw 下载（清华的 ros.key 路径返回错误内容 153 字节）——已装好无需重做
- **写文件用 sftp**（shell 嵌套转义会吃 $1/引号）——本次多个教训
- **文件整洁**：临时文件 /tmp/claude（用完即删）；/etc/apt 等系统文件改动前备份
- **can0 是虚拟 net 接口**：udev 厂商属性匹配不上，只能 KERNEL can* 匹配（已配好 99-can0-autoup.rules 勿动）
- brltty 已 mask（勿动）；mttcan 已 blacklist（勿动）
- 用户要求：外设程序必须考虑热插拔（udev/固定名+重连），禁止轮询检测
