# AGENTS.md — AI间交流（AI 使用说明书）

> AI 向规则；人类向说明见同目录 `README.md`。项目全局约定（git 纪律/工程约束/交接协议）见项目根 `AGENTS.md`。

## 本目录定位

情报交换站：让未参与用户对话的 AI 同步项目情报。**不是使用说明书**（使用说明书在各开发侧目录的 README/AGENTS）。

## 进入顺序
1. 读项目根 `AGENTS.md`（全局约定）
2. 读本文件
3. 读 `情报.md`（当前事实）
4. `git log --oneline -20` 看历史变更（记录.md 已于 2026-08-23 废弃，历史一律查 git log）
5. 读 `消息\` 里最新的交接文件（若有）

## 规则
1. 所有 AI 同级；本目录与论文主控体系无关
2. `情报.md` 由各 AI 共同维护，事实变化即更新；补充/异议先写 `消息\`，重要变更并入 `情报.md`
3. **情报更新须经用户确认**：每次获得新信息，先问用户是否更新，同意后才写入
4. **长期记忆**（情报.md / 全局记忆）：归档后**不允许删除**，只增不改（改前先问用户）；历史变更查 git log
5. **短期信息**（消息\）：交接文件在新对话完成接手后**允许删除，但必须先经用户同意**；普通消息处理完删除
6. 内容只放本目录；根 README 只写项目使用说明（人类向）

## 对话交接
- 完整协议见项目根 `AGENTS.md` 的「对话交接协议」章节（一句话触发：接手方读领域 AGENTS.md → 情报 → git log → 向用户汇报确认；退休方写 `消息\交接_*.md` 并提交）。
- 交接文件模板：`消息\交接模板.md`。
