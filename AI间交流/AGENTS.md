# AGENTS.md — AI间交流（AI 使用说明书）

> AI 向规则；人类向说明见同目录 README.md。项目全局约定（git 纪律/工程约束/接手顺序）见项目根 AGENTS.md。

## 本目录定位

情报交换站：让未参与用户对话的 AI 同步项目情报。**不是使用说明书**。

两套文档的分工（2026-11-06 明确）：

- **模块内 README.md（人）/ AGENTS.md（AI）＝自足的使用说明书**。目标是整个子目录能被单独拷走，别的 AI/人拿到就能用；模块细节（寄存器、时序、代码、UI、踩坑）都写在这里。
- **本目录（情报）＝跨模块、跨时间/空间的事实与决策索引**。只放会影响多个模块的结论、全局决策、当前状态与待办；不复制模块文档的细节，需要时给指针。

## 进入顺序

1. 读项目根 AGENTS.md（全局约定）。
2. 读本文件。
3. 读 情报.md（目录页）→ 先读 情报\01_当前状态.md，其余分册按需翻；追来历看 99。
4. git log --oneline -20 看近期提交。
5. 向用户汇报「已接手〔领域〕。现状：… 待办：… 下一步：…」，确认后开工。

> 旧 交接\ 机制自 2026-11-06 停用：情报分册已能承载跨会话状态，不再要求退休方写四段式交接文件。历史交接文件留档勿删。

## 规则

1. 所有 AI 同级；本目录与论文主控体系无关。
2. **一事实一处**：同一事实只在一个分册定义，别处只引用、不抄写。
3. **一册一个「最后更新」**：只放文首（YYYY-MM-DD），改事实后同步本册与目录页；正文不再到处盖日期戳，日期只留在 99 的变更日志和确有意义的决策句里。
4. **改事实先改分册**：覆写旧句、不留旧口径；被删原文进 99 的「覆写记录」。完成或废弃的条目从 01 移出，结论进 99 变更日志。
5. **99 只做两件事**：按日期一行式变更日志；被覆写/删除原文的存档。99 不定义现行事实；历史一律另查 git log。
6. **模块细节不进本目录**：寄存器/时序/代码/UI 实现写模块 README/AGENTS；本目录只放跨模块有效结论与项目级决策。模块文档保持可单独拷走使用。
7. **更新授权分级**：技术事实落盘不必逐条问用户（按 2026-11-03 决策边界）；但「改口径、删事实、改册结构、改安全边界、对外表述」须用户过目，会话收尾一次性汇报。
8. **改目录须经用户同意**：情报.md 的目录表、分册的增删改名，先说清「改什么、为什么、影响哪几处」；只改分册内部内容不必逐条问。
9. **跨库交流**：先读对方 AGENTS 按其格式；条目加〔外部·库名〕前缀；改对方事实/正式文档需用户当场过目。用户发话即为确认。
10. **Jetson 远程操作可见性（2026-09-03 用户规定，全体 AI 默认遵守）**：对 Jetson（192.168.31.114，密码 1）的一切远程操作必须在 Jetson 的 tmux ops 会话内执行（tmux send-keys -t ops 命令 + tmux capture-pane -t ops -p 读输出）；用户可随时在 Jetson 桌面双击「查看Claude操作」或终端 tmux attach -t ops 实时查看；不得旁路 SSH 直连执行；用户说「我要看」时立即同步进展到会话；sudo 密码交互若远程卡壳，请用户手动在窗口输入。
11. **条目格式**：不再强制「提出:〔模块〕 → 针对:〔模块〕」；需要说明来源时写「来源:〔模块〕」。跨库条目保留〔外部·库名〕前缀。措辞上「上位机」一律指 电机上位机开发；「交互界面」写全称，不得用「上位机」指代。

## 多会话信息获取模型

| 场景 | 信息获取方式 |
|---|---|
| 空间相同 + 时间不同（先后接力） | 领域 AGENTS → 情报目录页 → 01 → git log → 汇报确认 |
| 空间相同 + 时间相同（多会话并发） | 情报分册是共享事实层，事实变化即写（按规则 7 的授权）；git 提交后其他会话可见 |
| 空间不同 + 时间相同（多机并行） | 同上；事实经 git 提交/拉取跨机同步 |
| 空间不同 + 时间不同（完全异步） | 同上；对话级状态写 01 待办总表，不另设交接文件 |

核心原则：**项目级事实走情报分册；模块细节走模块 README/AGENTS；历史走 git log**。三层各司其职。

## 接手与退休

- **接手方**：读领域 AGENTS → 情报目录页 → 01_当前状态 → git log → 向用户汇报确认后开工；验收类任务先报方案，不擅自改代码。
- **退休方**：把未完成项写进 01 的「待办总表」；提交代码与情报；不再写交接文件。口头交代不算数。
- **领域 AGENTS.md 清单**（已建 7 个：项目根、AI间交流、ESP32_for_WiFi_and_BLE_CAN、IMU_HI12S2_MI1、Jetson_Orin_NX、机械臂操作交互界面、电机上位机开发）。遇到未建文档的领域，先向用户报告「该领域无对接文档，是否补齐」，不得直接开干。
